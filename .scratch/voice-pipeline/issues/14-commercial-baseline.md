# 14: 商用 TTS 对照

Type: prototype（HITL）
Status: resolved
Blocked by: 13

## Question

用豆包语音 2.0 的预置或设计音色（不上传声优原声）做〈2002〉：
- 音色稳定性和情绪表现能到什么程度；
- 和本地方案差多少，作为"放开开源限制"的参考上限。

## Answer

**定论：豆包语音合成 2.0 的预置音色听感不如本地方案（IndexTTS-2.5 全员版），暂停，不再调**。

- **试听**（用户原话）："我觉得听上去不是很好，还不如我们自己做的，如果再调教还要花token，我觉得暂时就算了"。
- **做法**：只发文字，没开音色设计，没做声音复刻。
  - 音色：每个角色试了 4 个预置音色，用户听完定的是春希儒雅逸辰、雪菜甜美桃子、依绪直率英子、武也小天。四个音色两两相似度 ≤0.44。春希的旁白、心里话和台词用同一个音色，靠讲述的语音指令和混音区分；
  - 情绪：语音指令（`additions.context_texts`，不计费）用剧本情绪的描述（`moods.HINT`）加表演提示（`instruct`）。情绪实测里试了 5–8 种做法，用户听着这种最好；
  - 其他参数：
    - `audio_params.emotion` 乱写一个值也不报错，听不出效果，不用；
    - 表现力增强版 `seed-tts-2.0-expressive` 能用，但用户没选；
    - `loudness_rate` 调了也会被混音的逐句响度统一抵消掉；
  - 语速：每个角色一个 `speech_rate`，把语速拉到定妆音的目标（+30 / −15 / 0 / −25）。
- **指标**（和 IndexTTS 全员版、混合版-5090 比，都从 MP3 算）：
  - 认人 101/101，和全员版一样；
  - 像自己的锚点：中位 0.74 / 0.74（全员版 0.83 / 0.84），没有大掉的句子，最低 0.41；
  - 字错率中位 0，>0.3 的句子小样 3 句、〈2002〉3 句（全员版 4 / 5），人名没有读错；
  - 不足：像原声只有 0.1–0.4，预置音色本来就不是本人；春希约 100 Hz，比定妆音的 158 Hz 低了大半个八度；〈2002〉雪菜每秒 2.6 字，比目标 3.47 慢。
- **速度和费用**：
  - 速度：请求每字 0.075 秒，全书单连接约 1.5 天，不占 GPU；
  - 计费：按送去的文字全长算，标点也算。全书剧本实数 154.1 万字（含标点），约 462 元；
  - 本票用了 4,422 字，在免费额度内，没花钱；
  - 每次请求都记在 `out/volc/usage.jsonl`，`uv run python -m readbook.volc 用量` 汇总。
- **音色设计**：没开。它改的主要是音色像不像，管不了稳不稳；而且不拿豆包做正式方案，也就不需要了。
- **踩到的坑**：剧本的 `pause` 改过之后，旧 MP3 要重新混音再评测。否则 `evaluate` 按新剧本切句会报 `min() iterable argument is empty`。这次是 18 号票在我合成〈2002〉的过程中写回了停顿，已经从缓存重新混音，没有重复计费。
- **对"商用 TTS 加 RVC"**（地图里还没定的那一项）：它等的两张票之一，也就是这张，有结论了：预置音色的听感本身就不如本地方案。

**文件和命令**：
- 完整数据和对比：`docs/audiobook/小说转有声书商用对照.md`；
- 成品：`books/wa2/trials/volc/*-豆包2.0-指令+情绪.*`，包括 MP3、带时间戳的对照剧本、指标；
- 试音和情绪实测：`books/wa2/trials/volc/试音/`、`情绪/`；
- 命令：`uv run python -m readbook.volc_passage 试音|情绪|锚点 <版本>|<版本> <名字>`，例如 `指令+情绪 小样`。
