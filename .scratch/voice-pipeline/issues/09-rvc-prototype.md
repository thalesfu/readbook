# 09: RVC 能不能把音色彻底稳住

Type: prototype（HITL）
Status: open
Blocked by: 03, 05, 06
搁置：2026-10-30 用户定的，不挡 15 号票。IndexTTS-2.5 主线的音色已经过门槛、认人 100%，先不做 RVC。15 号票定完规格后，要是音色还不稳，或者想试 RVC 重新过一遍声码器能不能去掉 IndexTTS-2.5 的电子颤音，再拿出来。

## Question

按"RVC 在 50 系 Windows 上怎么训、怎么用"的结论，用游戏原声训练春希、雪菜的 RVC 模型，对基线的合成输出逐句做音色转换：
- 同一角色的漂移是否消失（声纹最低值、二维表）；
- 情绪是否保留；
- 有没有伪影；识别字错率上升多少；
- 试听感受。
