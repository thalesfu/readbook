# 02: IndexTTS-2.5 在 5090 上怎么用

Type: research（AFK）
Status: resolved
Blocked by: 无（可以立即开始）

## Question

查清楚用 IndexTTS-2.5 做"音色固定、逐句换情绪"需要的事实：
- 2.5 的权重和推理代码是否已经公开、在哪；和 2.0 的接口差异；
- 在 Windows 和 50 系显卡上的安装要点；fp16 和加速选项；预期实时率；
- 情感向量 8 维（喜、怒、哀、惧、厌恶、忧郁、惊讶、平静）怎么从我们的 10 类情绪映射过来；
- `emo_alpha` 强度怎么设；用文字描述和用向量的取舍；
- 已知的音色泄漏问题和缓解办法。

产出调研笔记，标明事实和推测。

## Answer

调研笔记在分支 `research/indextts25` 的 `research/indextts25.md`（提交 887b87e），依据是官方仓库源码（快照 d9e41aa）、HuggingFace API、论文和 issue。要点：

- **发布情况**：2.5 已于 2026-08-10 公开，代码是 `indextts/infer_v2_5.py`，权重是 `IndexTeam/IndexTTS-2.5`。和 2.0 的差别：
  - 多了必填参数 `lang` 和 `duration_factor`（可以调时长，正好补上语速问题）；
  - 半精度只支持 bf16，不支持 fp16；
  - 情感样本库和情感模型两版相同，同一张情绪映射表都能用。
- **情绪向量的实际算法**：从固定的情感样本库里挑和定妆音最像的示例加权混进去，权重总和越大越容易漏音色。官方 WebUI 会把总和压到 0.8 以下，Python API 不会自动做，要自己调 `normalize_emo_vec()`。定妆音只取前 15 秒，要先裁到 15 秒以内。
- **Windows 安装**：只装 `--extra webui`（torch 2.8 cu128 原生支持 50 系），开 bf16。DeepSpeed 和 flash-attn 在 Windows 上难装，放到第二阶段、在 WSL2 里试。官方数据是 4090 上实时率约 0.20，5090 笔记本推测 0.25–0.5，短句更慢。
- **10 类情绪映射（推测）**：
  - "平常"不传向量；
  - 开心、兴奋、生气、难过、哭腔、冷淡、惊讶都有具体向量，归一化后总和 0.56–0.8；
  - "害羞""轻声"在 8 维里没有对应，改用同一角色自己的参考音频；
  - 以向量为主，`emo_alpha` 当全书或角色级的强度旋钮（0.7–1.0），文字模式只用来辅助校准映射。
- **音色泄漏**：多方印证，强情绪下更明显。另有多名用户反馈 2.5 的中文不如 2.0，维护者未回应。缓解办法：
  - 保持 `use_random=False`，控制权重总和；
  - 用同一角色自己的情绪参考；
  - 每句过音色门槛，不达标就重做；
  - 定主力版本前，在 5090 上做 2.0 和 2.5 的对比。
