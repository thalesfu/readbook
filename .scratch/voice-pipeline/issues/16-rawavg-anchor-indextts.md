# 16: 用原声平均版重做定妆音，交给 IndexTTS-2.5

Type: prototype（HITL）
Status: resolved
Blocked by: 07, 10

## Question

两张票各有一半：
- **IndexTTS-2.5**（10 号票）：情绪到位、速度快、音色也稳。但它复刻的是 VoxCPM2 做的定妆音，像锚点 0.87，像原声中位只有 0.59 / 0.56（小样 / 〈2002〉）。
- **原声平均版**（07 号票）：只用本人原声的平均说话人向量，像原声 0.64 / 0.58，但情绪进不来。

这张票把两边接起来：
- 用原声平均版（Qwen3）重做每个角色的音色锚点，用和旧定妆音一样的中文文本；
- 再把它当 IndexTTS-2.5 的说话人参考，做小样和〈2002〉；
- 只换音色锚点：情感参考（讲述定妆音等）和情感向量都照 10 号票，不变。

要回答：
- **新锚点本身是不是比旧定妆音更像原声**。先量这一步，不更像就不往下做；
- **用了新锚点后**，IndexTTS-2.5 的像原声、过音色门槛、认人准确率有没有提高，情绪是否仍然到位；
- **语速**：原声平均版偏慢，这会不会被带进 IndexTTS 的成品；
- **速度**有没有变化。

规则对所有角色一样，不按人特调。和混合版基线（`books/wa2/baseline/*-混合版-5090.*`）、10 号票的 2.5 版（`books/wa2/trials/indextts/`）比。

## Answer

**定论：四人都用原声平均锚点当 IndexTTS-2.5 的说话人参考（全员版）**。情感参考和情感向量照 10 号票不变。

- **试听**（用户在 Mac 上听，原话）：
  - 只换春希版："春希我觉得挺好的，除了有的地方有些合成音的颤音的感觉。但是我觉得雪菜有的时候会感觉没有春希好。"
  - 全员版："我觉得比刚才好"。
- **锚点本身**：声纹量出来只有春希明显更像原声，但试听以全员版为好。用哪套锚点不能只看锚点本身的声纹，以试听为准。全员版规则对所有角色一样。
- **全员版成品**（和 10 号票的 2.5 版比）：
  - 春希：台词像原声 0.51 → 0.72，讲述 0.55–0.58 → 0.68；
  - 雪菜：略更像（候选级 +0.03），和别人分得更开，语速快了；音高偏高约 5%（311–320 Hz，原声约 300），读错的句子多两三句；
  - 依绪：语速接近目标；
  - 武也：小样唯一的一句没过门槛（0.44）；
  - 过门槛小样 29/31、〈2002〉47/47，认人 100%。
- **问题里的几项**：
  - 音高：新春希锚点 174 Hz，没有带进成品；10 号票春希「轻声」被抬高的问题也消失了；
  - 语速：原声平均版"偏慢"没有整体带进来，锚点的语速会带进成品：春希台词慢约一成，正好落在目标；雪菜、依绪变快；
  - 情绪：按向量照旧到位，试听没有提情绪变差；
  - 速度：只算用到的候选的生成时间，每字 0.366 → 0.321 秒；按 10 号票的比例折算，全书约 7.5 天（10 号票 8.5 天）。
- **顺手修的**：小样 56 号依绪的 "Ｈａｐｐｙ　Ｎｅｗｙｅａｒ"。`synth.tts_text` 原来没把全角空格转半角，被读成怪音；现在夹在全角字母数字之间的全角空格一起转，全员版重做了这一句。
- **留给后面的**：
  - 春希讲述有合成颤音：新锚点本身音高抖动大（85 对 13 音分），可试锚点候选 1，或把音高抖动加进锚点挑选规则；
  - 「呼」这类单字叹词太短（0.48 秒）、「轻声」想更轻更慢：属于表演控制，和 11 号票一起；
  - 雪菜音高偏高、个别词读错；
  - 武也要在戏多的段落上再听。

完整数据和做法见 `books/wa2/trials/rawavg-anchor/原声平均锚点-对比.md`，MP3、带时间戳的对照剧本、指标都在同一目录。全员版是 `*-IndexTTS-2.5-原声平均锚点全员.*`，命令 `uv run python -m readbook.index_passage 2.5-原声平均锚点全员 小样|"2010-11-25 〈2002〉"`。

**只换春希版的数据**（中间一版）：
- **新锚点**：只有春希比旧定妆音更像原声（0.57 → 0.79）。雪菜、依绪持平，武也更差。
  - 用户定的规则：每人用像原声更高的那个锚点，所以只换了春希。
- **换上后，春希在 IndexTTS-2.5 成品里明显更像本人**：
  - 像原声中位：小样台词 0.51 → 0.72，讲述 0.55 → 0.68；〈2002〉讲述 0.58 → 0.68；
  - 同一句、同一种子的候选配对（不经挑选）：台词 +0.22，讲述 +0.10；
  - 整段像原声中位：小样 0.59 → 0.63，〈2002〉0.56 → 0.65；
  - 过音色门槛小样 31/32、〈2002〉47/47，认人 100%，和 10 号票一样。雪菜、依绪、武也的句子和 10 号票逐样本相同。
- **音高没被带进来**：新锚点 174 Hz，但成品里春希平常台词 160 Hz、讲述 138 Hz，贴着目标。
  - 还顺带解决了 10 号票的「轻声」问题：同一个轻声向量，春希从 161–195 Hz 回到 134–144 Hz。
- **语速带进来一部分**：台词慢了约一成（4.45 → 3.91 字/秒），正好落在他的目标 4.01；讲述只慢 2–4%。
- **和武也**：两个锚点本身更近了（0.38 → 0.62），但成品里春希"像自己 − 像最像的别人（都是武也）"反而拉大（+0.15～0.18 → +0.21～0.24）。
- **情绪**：情感向量和讲述参考都没动。emotion2vec 只能当旁证：春希平常讲述被认成"生气"的从 26/31 降到 13/31，难过的心里话被认成"难过"的从 0/4 升到 3/4。到不到位看试听。
- **速度**：基本不变，全书仍约 8.5 天。
  - 单个候选的实时率扣掉机器状态的差别后没变；
  - 机器状态的差别拿同一份工作算：其他人的句子今天慢了约一成；
  - 小样台词慢了，同样的字多出 8% 音频。

### 第一步：新锚点本身像不像原声

对比表在 `books/wa2/trials/rawavg-anchor/锚点对比.md`，新锚点在同目录的 `锚点/`。

| 角色 | 旧定妆音 | 新锚点候选 中位（最低–最高） | 挑中的新锚点 | 差 |
|---|---|---|---|---|
| 春希 | 0.57 | 0.76（0.75–0.79） | 0.79 | **+0.22** |
| 雪菜 | 0.65 | 0.55（0.53–0.63） | 0.63 | −0.02 |
| 依绪 | 0.71 | 0.68（0.60–0.70） | 0.70 | −0.01 |
| 武也 | 0.77 | 0.64（0.53–0.70） | 0.53 | **−0.24** |

- 数字是像原声：CAM++ 和本人 300 句原声的中心比，和 `readbook.evaluate` 同一把尺子。IndexTTS 只取前 15 秒，截断后的数字和整段一样（只有依绪差 0.002），表里不分开写。
- **只有春希明显更像**，8 个候选全都比旧定妆音高。他的旧定妆音是四人里最不像的（0.57），10 号票的 2.5 里他也是最不像原声的人（小样台词 0.51、讲述 0.55，〈2002〉讲述 0.58）。
- **雪菜、依绪持平**：最像的候选也没超过旧定妆音。
- **武也更差**：8 个候选里 7 个音高 165–195 Hz，离原声的 144 Hz 太远，没过质检，挑中的是唯一过质检的那个，也是最不像的（0.53）。不看质检，最高也只有 0.70，仍低于旧定妆音的 0.77。旧定妆音的音高其实也偏高（175 Hz），但像原声 0.77。
- 旧定妆音里，依绪、武也的锚点当初就是按"像本人原声"从 VoxCPM2 的候选里挑的，春希的是按音高、语速挑的。这能解释为什么只有春希提升大。
- **分不分得开**：新锚点"像自己 − 像最像的另一个人"的差，春希、雪菜、依绪都比旧的大（+0.17→+0.24、+0.22→+0.29、+0.23→+0.27），武也持平。但新春希和新武也更近了：两个锚点之间 0.38 → 0.54。
- **音高、语速**：新春希 174 Hz，比旧定妆音（158 Hz）和原声目标（160 Hz）高约一成；语速 3.54 字/秒，比旧的 4.01 慢。

**做法**（`readbook/rawanchor.py`，规则对所有角色一样）：
- 文本和旧定妆音一样，套读音表；Qwen3 只用说话人向量，向量取本人 60 句原声的平均（07 号票的原声平均版），温度 0.6，固定种子，每人 8 个候选，不变速；
- 挑选：去掉读错的（字错率比这批最低的高出 0.1 以上；人名地名常被识别成同音字，比如峰城祭→封城祭，所以不用绝对值）和质检不过的（时长、句内变调、音高语速离原声目标太远），剩下的取像原声最高的；
- `uv run python -m readbook.rawanchor` 生成候选、挑选、出对比表，并把"采用"（新锚点比旧定妆音更像原声才用新的）写进 `锚点.yaml`；候选在 `out/rawanchor/`。

### 第二步：IndexTTS-2.5 只换春希的说话人参考

- 情感参考、情感向量、质检目标、种子、挑选规则全照 10 号票；挑选时的"像锚点"和所用的锚点比。
- 代码：
  - `readbook/index_passage.py` 加了 `2.5-原声平均锚点` 版本，按 `rawanchor.adopted()` 取说话人参考；
  - 加了 `pair` 子命令，两版同一句同一种子的候选逐个配对，看像原声、认人、和最像的别人差多少、音高、变速前语速、速度；
  - `readbook/evaluate.py` 加了 `--锚点 <名字>=<wav>`，换掉某个人的锚点。
- 命令：
  ```
  uv run python -m readbook.rawanchor
  uv run python -m readbook.index_passage 2.5-原声平均锚点 小样|"2010-11-25 〈2002〉"
  uv run python -m readbook.index_passage pair 小样 2.5 2.5-原声平均锚点
  uv run python -m readbook.evaluate 小样 <MP3> --锚点 春希=books/wa2/trials/rawavg-anchor/锚点/春希.wav
  ```

### 试听反馈和全员版

逐句的反馈、查到的原因和全员版的数据，见对比文档的"试听"和"全员都换原声平均锚点"两节。

- **春希的颤音**：用户点名的〈2002〉31–50 和小样 76 都是换了锚点的春希讲述。
  - 新春希锚点本身的音高抖动是旧锚点的好几倍（85 对 13 音分），新版讲述句的音高抖动中位从 66 涨到 106 音分；
  - 颤音很可能是新锚点带进来的，但这个指标会把语调起伏也算进去，还不是硬证据；
  - 春希候选 1（像原声 0.76，抖动只有现在一半）可以换上试试。
  - 小样 3 号武也的颤音是 10 号票原来就有的（同一份音频），IndexTTS 本身也会出颤音。
- **和锚点无关的问题**（都是 10 号票原来就有的）：
  - 小样 56 号依绪的 "Ｈａｐｐｙ　Ｎｅｗｙｅａｒ"：全角空格没转半角，被读成怪音，是 `synth.tts_text` 的文本规整问题；
  - 〈2002〉24 号「呼」只有 0.48 秒，用户希望拉长；
  - 用户觉得「轻声」整体可以更轻、更慢。这两条属于表演控制，和 11 号票相关。
- **全员都换原声平均锚点**（用户要求）：
  - 雪菜：像原声略高（候选级 +0.03），和别人分得更开，语速快了，要拉快的句子少了；但音高从偏低（275–291 Hz）变成偏高（311–320 Hz，原声约 300），读错的句子多了两三句；
  - 依绪：音色不变，语速接近目标；
  - 武也：小样唯一的一句像原声 0.72 → 0.44，没过门槛；
  - 速度：每字 0.54 → 0.43 秒（小样）、0.30 → 0.26 秒（〈2002〉）。
  - 用户试听："我觉得比刚才好"，采用全员版。
