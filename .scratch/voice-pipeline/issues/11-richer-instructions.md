# 11: 升级表演指令值不值

Type: prototype（HITL）
Status: resolved
Blocked by: 10, 19

## Question

剧本化时给每句补"人物性格卡 + 场景 + 前后 1–2 句上下文"，生成更细的表演提示，交给有指令能力的引擎：
- 语气是不是更贴人物性格；
- 会不会反过来带偏音色。

和不升级的版本比。

## 现状（2026-10-30 补充）

开票时设想的"有指令能力的引擎"是 Qwen3 的 instruct。后来主线换成了 IndexTTS-2.5（10、16、17、19 号票），它不吃自由文字的指令，能控制的是：
- **情感向量**：8 维（喜、怒、哀、惧、厌恶、忧郁、惊讶、平静），加 `emo_alpha` 强度。权重总和压在 0.8 以下，否则漏音色（02 号票）；
- **情感文字**：`emo_text` 走它自带的情感模型，把文字转成向量；
- **情感参考音**：`emo_audio`，现在讲述模式用讲述定妆音；
- **时长**：`duration_factor`（2.5 新增）；
- **混音**：每句的音量（现在一律拉到同一响度）、句间停顿（18 号票的 `pause`）。

现在的做法：
- 剧本化（`readbook/scriptize.py`）每句给一个 `mood`（10 类之一）和一句不超过 15 字的 `instruct`，角色表只有一行 `desc`，没有场景和前后文；
- IndexTTS-2.5 只用 `mood`，按 `index_passage.EMOTION` 的固定表换成向量；`instruct` 完全没用上。

所以这张票在 IndexTTS-2.5 上要回答的是：**拿性格卡、场景、前后文生成更细的表演设置，逐句定向量、强度、时长、音量，比"10 类情绪查固定表"好不好**。

一起解决试听里留下的两条（16 号票）：
- **「呼」这类单字叹词太短**：〈2002〉24 号「呼」只有 0.48 秒，用户希望拉长；
- **「轻声」想更轻、更慢**：现在混音把每句响度拉平，轻声和平常一样响。
  - 10 号票里，轻声向量曾把春希音高抬了 12–28%；16 号票换了锚点以后回到 135 Hz 左右，改的时候要盯住音高。

## 做法起点

- **基线**：19 号票的成品（`books/wa2/trials/resample/*-重采样-缓4k.*`），用的是 17 号票定版锚点（`2.5-原声平均锚点新规`）、18 号票的停顿、soxr、缓4k。
- **不动已有剧本字段**：升级后的表演设置写进新字段（或新文件），这样和基线能同一句、同一种子配对比较。
- **性格卡写进仓库**，比如 `books/wa2/cast.yaml`，所有角色同一格式。规则对所有角色一样，不按人手调。
- **可以比的几条路**（不限于这些）：
  - Claude 直接给 8 维向量和强度；
  - 给更细的情感文字，交给 `emo_text`；
  - 只升级强度、时长、音量，向量仍查表。
  - 时长和音量哪些归合成（`duration_factor`），哪些归混音，要试。
- **会重新合成**，要用 GPU。

## 要回答

- 试听：语气是不是更贴人物性格，「呼」和「轻声」是否解决。用户以试听为准，emotion2vec 只当旁证；
- 音色：像原声、过音色门槛、认人和基线比，有没有被情绪带偏；读音（字错率）；
- 成本：剧本化多出来的 `claude -p` 调用和字数，合成速度有没有变；
- 结论：正式流程用哪一种，参数是多少，怎么并进剧本化。

## Answer

**定论：升级。剧本化之后单独问一遍表演设置，Claude 看性格卡和整段剧本，逐句给 8 维情感向量（B），加语速倍数和音量；语速、音量都放在混音里**。

- **试听**（用户原话）：
  - 试听合集（25 句，每句 基线 → A → B）："大多数B更好一些，有些A好"；
  - 时长 A/B（基线 → 合成拉长 → 混音变速）：选第三遍"混音变速"；
  - 看完定版的数据和结论："可以结票"。
- **比了三种做法**，三种共用同一次 `claude -p` 给的语速和音量，只差情绪从哪来：
  - A：情绪仍按 `mood` 查表，Claude 只给强度。不带偏音色，但有一句春希轻声被抬到 167 Hz；
  - B：Claude 直接给向量。不带偏音色，能按人物把情绪混起来（雪菜强撑笑脸 = 喜 + 忧郁），平常台词也可以加一点淡淡的情绪；
  - C：Claude 写情感描述，交给 IndexTTS 自带的情感模型转成向量。**不能用**：
    - 它只认一种主情绪，浓度都顶到 0.8 上限，「淡淡的」「很轻」不认，还会认错（「带着哭音，轻轻责怪」→ 怒）；
    - 音高被抬上去：春希台词 150 → 175 Hz、轻声约 200 Hz，武也 159 → 225 Hz（过门槛 3/4 → 1/4），依绪 232 → 282 Hz。
- **参数**：
  - 性格卡：`books/wa2/cast.yaml` 新加 `card`（性格 / 情绪外露 / 声音），9 个主要角色同一格式，没有卡的用 `desc`；
  - `vec`：8 维 0–1，和 `index_passage.EMOTION` 同一尺度，照旧过 `normalize_emo_vec`（偏置、总和压到 0.8）；全 0 是不加向量（本人平常的声音）。这次过完偏置后总和中位 0.61（0.31–0.80）；
  - `tempo`：0.5–1.25。合成不拉长，候选读进来先用 atempo 变速，挑选时目标语速乘 `tempo`，时长上限除以 `tempo`；
  - `gain`：−9 到 +3 dB。每句拉平响度、过完后期链以后再加减（`mix.assemble`）；
  - 讲述模式（叙述者情绪平常的旁白、心里话）不换情绪，照旧用讲述定妆音，只用 `tempo` 和 `gain`；
  - 引擎、锚点、种子、挑选、停顿、缓4k 都照 17–19 号票。
- **音色**：定版（`2.5-表演B混音`）和 19 号票的基线比：
  - 小样：过门槛 30/32（基线 30/31），像原声中位 0.62（0.62），认人 43/43；
  - 〈2002〉：过门槛 51/51（47/47），像原声中位 0.63（0.65），认人 58/58；
  - 分母变了，是因为放慢后多了几句够 1.5 秒；
  - 同一句、同一种子的候选配对（不经挑选，只差情绪向量）：像原声差 −0.02～+0.02，过门槛、认人不变；
  - 混音变速在被拉长的句子上比合成拉长再低 0.01–0.02（〈2002〉春希旁白 −0.021 对 −0.010），都还过门槛。
- **「呼」和「轻声」**：
  - 「呼」0.28 → 1.28 秒（Claude 给的语速 ×0.55）；
  - 轻声比同一段的其他台词轻 2.4 dB（小样）、3.9 dB（〈2002〉），基线是 0；慢了 10–30%；
  - 春希轻声 131–155 Hz（基线 130–158），没被抬高。
- **读音**：字错率 >0.3 的小样 3 句、〈2002〉3 句（基线 4、5 句），几乎都是人名（「依绪」→「依序」、「雪菜」→「学菜」），各版都有。
- **emotion2vec**（旁证）：有明确情绪的句子里对上 `mood` 的，三版都没比基线多。
- **成本**：
  - `claude -p`：每段剧本一次（Opus 5.5）。〈2002〉65 句 71 秒、$0.60，2011-01-01 157 句 179 秒、$0.95（列表价）。合计每句约 $0.007、1.1 秒。全书约 11 万句约 $780、35 小时（串行）；
  - 这次一次要了七个字段，正式流程只要 `vec`、`tempo`、`gain`，返回能少一半左右；
  - 合成速度不变：每字 0.40 / 0.27 秒（基线 0.43 / 0.26）。语速、音量放在混音里，要改不用重新合成。
- **怎么并进剧本化**：
  - 照 18 号票 `scriptize.pauses` 的做法，剧本化之后单独问一遍（`perform.label` 的提示词：性格卡、整段剧本和已有字段、查表值、引擎限制），写进剧本新字段（如 `perform: {vec, tempo, gain}`），已有字段不动；
  - 合成时 `index_passage` 有 `perform` 就用它的向量代替查表，`mood` 还用来判断讲述模式；
  - 挑选前按 `tempo` 变速，混音时按 `gain` 加减音量；
  - 现在这份表演设置在 `books/wa2/trials/perform/表演-<剧本>.jsonl`，接进 `passage.load_rows` 留给 15 号票定规格时做。
- **留给后面**：
  - 用户说有些句子 A 更好，没逐句问是哪几句；
  - Claude 给的音量在小样偏保守（轻声 −3 到 −4 dB），实际只轻了 2.4 dB，整段峰值限幅又吃掉 1–2 dB；
  - 字错率多出来的都是人名，可以在读音表里补「依绪」「雪菜」。

做法、各版数据和试听时间点见 `books/wa2/trials/perform/表演-对比.md`。同目录还有：
- 定版和 A/B/C 各版的 MP3、对照剧本（多一列「表演」）、指标；
- 试听合集、时长 A/B、表演设置和 `claude -p` 用量。

命令：
- `uv run python -m readbook.perform 标注 小样|"2010-11-25 〈2002〉"`
- `uv run python -m readbook.index_passage 2.5-表演B混音 小样|"2010-11-25 〈2002〉"`
