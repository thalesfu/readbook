# 03: RVC 在 50 系 Windows 上怎么训、怎么用

Type: research（AFK）
Status: resolved
Blocked by: 无（可以立即开始）

## Question

查清楚给每个角色训练一个 RVC（或 Applio 等分支）模型、对 TTS 输出做音色转换所需的事实：
- 选哪个实现，以及在 Windows 和 50 系显卡（cu128）上的安装；
- 训练数据：要多少分钟、怎么切片、采样率、要不要去掉情绪极端的句子；
- 音高算法（如 rmvpe）的选择；`index_rate`、`protect`、`filter_radius` 等推理参数的建议值；
- 同性别和异性别之间的移调；
- 对 TTS 合成音做转换时，情绪、清晰度、伪影方面的已知经验；
- 用日语训练、转换中文语音有没有问题。

产出调研笔记，标明事实和推测。

## Answer

调研笔记在分支 `research/rvc` 的 `research/rvc.md`（提交 a8d1026），依据是 RVC 上游和 Applio 两个仓库的源码，每条结论都标了是事实还是推测。要点：

- **实现**：首选 Applio：安装脚本走 cu128 加 torch 2.11，命令行子命令齐全，适合批处理。选 RVC 架构加 HiFi-GAN 时，模型和上游 RVC 通用。备选是上游 RVC 2.3 的 50 系整合包（2026-07 发布）。
- **数据**：官方推荐 10–50 分钟，我们的素材远超这个量，关键在挑选。
  - 先取约 45 分钟训第一版，再用 2–3 小时训一版对照；
  - 剔除尖叫、耳语、哭喊、带混响或电话滤镜的句子；
  - 棚录干声不用去混响、降噪；
  - 采样率 40k，用默认切片。
- **推理参数起点**：
  - 音高算法用 rmvpe；
  - 移调：同性别 0，异性别 ±12；
  - `index_rate` 0.3，在 0–0.75 之间扫；
  - `protect` 0.33（0.5 等于关闭，Applio 界面上的说明文字写反了，以代码为准）；
  - `rms_mix_rate` 0.25–0.5；
  - `filter_radius` 用 rmvpe 时不起作用。
- **日语训练、转中文**：内容编码器 ContentVec 只用英语训过，声调来自输入的音高，所以机制上可行。风险是 index 会把中文特有的音拉向日语。所以 `index_rate` 要从低起步，用识别字错率来选。
- **局限**：
  - 没有找到"TTS 输出再做 RVC"在情绪和字错率上的一手量化数据，要自己测，建议拿雪菜试点；
  - RVC 只统一音色，不改音高轮廓，逐句的音高漂移得另外校正。
