# 07: 直接拿原声做参考，跳过定妆音

Type: prototype（HITL）
Status: resolved
Blocked by: 06

## Question

Qwen3 用日语原声加日文逐字稿做参考，不再经过 VoxCPM2 生成的定妆音：
- 音色是不是更稳（不再是复刻的复刻）；
- 会不会带出日语口音（看识别字错率加试听）。

和基线比。

## Answer

**结论**：
- **按票上的做法（原声加日文逐字稿，带文本复刻）不可用**：音色最像本人，但日语口音重到听不懂，九成句子的字错率超过 0.3。
- **改成只取原声的说话人向量，就没有口音**，音色也比混合版稳。说话人向量最好取几十句原声的平均（"原声平均版"）：
  - 过音色门槛：小样 20/30 → 30/30，〈2002〉33/43 → 45/46；
  - 不经质检的候选：小样 70% → 95%，〈2002〉75% → 100%；
  - 音高也贴原声。
  - 这条规则根本不用挑片段，对所有角色都一样。
- **代价**：语速偏慢；合成慢两成多，全书约 12 天（混合版 9.6 天）。
- **试听**：用户的结论是"07 的效果很好"（推荐试听的是原声平均版）。

**四个版本**的差别只在参考怎么进模型，其余（质检、重试、混音、参考的分工）都和混合版一样：

| 版本 | 参考 |
|---|---|
| 混合版（基线） | VoxCPM2 生成的中文定妆音，带文本复刻（ICL：参考码加逐字稿进上下文） |
| 原声版 | 挑出来的两句日语原声加日文逐字稿，带文本复刻 |
| 原声向量版 | 同样两句原声，只取说话人向量（官方 `x_vector_only_mode`），参考码和逐字稿不进上下文 |
| 原声平均版 | 只用说话人向量，取 60 句原声各自向量的平均 |

**试听文件**在 `books/wa2/prototypes/` 下，每份都带 `-对照剧本.md`（时间戳）、`-指标.md`、`-指标-逐句.jsonl`：
- 主要听 `小样-原声平均版.mp3`、`2010-11-25 〈2002〉-原声平均版.mp3`，和 `books/wa2/baseline/*-混合版-5090.mp3` 对比；
- `*-原声向量版.mp3`：音高偏低的那版；
- `*-原声版.mp3`：听口音用。

```
uv run python -m readbook.rawref                                    # 按规则重挑原声，写 books/wa2/voices/原声.yaml
uv run python -m readbook.passage 小样 --原声平均版                  # 或 --原声向量版、--原声版；〈2002〉同样
uv run python -m readbook.evaluate 小样|2002 <MP3>
uv run python -m readbook.stability 小样|2002 [--<版本>]             # 候选级稳定性抽查，见下
```

- **分角色过门槛**（混合版 → 原声平均版）：
  - 小样：春希台词 1/5 → 4/4，春希·讲述 5/6 → 6/6，雪菜 9/10 → 11/11，依绪 4/8 → 8/8，武也 1/1 → 1/1；
  - 〈2002〉：春希·讲述 21/30 → 31/32（最低 0.23 → 0.36），雪菜 12/13 → 14/14。
- **音高**（中位，括号里是原声）：

  | | 混合版 | 原声平均版 | 原声向量版 | 原声版 |
  |---|---|---|---|---|
  | 雪菜（302Hz） | 271 / 280 | **308 / 306** | 271 / 278 | 291 / 302 |
  | 依绪（242Hz） | 281 | **235** | 236 | 254 |
  | 春希·讲述（160Hz） | 156 / 143 | **163** / 147 | 141 / 139 | 154 / 150 |

  - 每格是"小样 / 〈2002〉"。
  - 只取两句原声的向量会把音高带低，取平均就回来了。
  - 带文本复刻的原声版音高也贴原声，说明参考码带进来的不只是口音。
- **语速**：两个只用说话人向量的版本都比混合版慢，大约每秒少 0.4–0.6 字；雪菜在〈2002〉里从 3.8 降到 3.2。质检只把语速拉回目标的 0.85–1.2 倍，而雪菜的目标本来就低（3.3）。
- **"认人·锚点"变差了，但不说明问题**：
  - 这里的锚点是 VoxCPM2 生成的定妆音，不是本人。小样从 28/30 降到 21/30，〈2002〉从 40/43 降到 25/46，主要是春希的句子离武也的定妆音更近。
  - 按本人原声中心算，区分度反而变好了。在干声上算春希每句"像自己"减"像最像的另一个人"：
    - 差值中位：混合版 0.15 / 0.16，原声平均版 0.21 / 0.18，原声向量版 0.24 / 0.21；
    - 最差一句：混合版是负的（被认成别人），原声平均版最差也有 +0.15 / +0.06。

**候选级稳定性抽查**（`readbook.stability`，新工具）：
- 成品经过质检和重试，跑偏的候选已经被筛掉了，所以成品的数字说的是"挑完以后"。要看参考本身稳不稳，得看挑之前的候选。
- 做法和 06 号票"不挑句子的对照"一样：每句按合成时同样的规则选参考，一批生成 5 个候选，不经质检；门槛和 evaluate 一样。

- **另做了一组对照，避开评测片段**：每人 8 句自己的中文台词（不在小样和〈2002〉里），每句 5 个候选。

  | 候选过门槛（音高中位） | 混合版 | 原声平均版 | 原声向量版 |

  | 春希 | 55%（171Hz） | 100%（150Hz） | 100%（137Hz） |

  原声平均版就是根据这组对照才做的，不是在评测片段上挑出来的。

**口音**：
- 原声版的识别结果里直接夹着日文。比如"新年快乐～春希。今年也多多关照了啊"被识别成"新年快樂春季今年や叩く鑑賞料は?"，"就在这个瞬间，新的一年造访了"被识别成"重罪弱神言神流珠年人造宝量"。
- 两个只用说话人向量的版本，字错率和基线逐项持平。口音有没有轻微残留，要靠试听。

**挑原声的规则**（`readbook/rawref.py`，对所有角色一样，不按人调）：
- **候选**：这个角色在 `bakeoff.REF_ROUTES` 三条路线里的有声台词，1.5–12 秒、测得出音高和语速，去掉小样和〈2002〉自己的句子。
- **平均向量（原声平均版）**：从全部候选里固定种子随机取 60 句，每句用 Qwen3 自己的说话人编码器算向量，取平均，再把长度缩放到单句向量的平均长度。合成时现算，60 句只要几秒。
- **锚点（原声版、原声向量版）**：只用 3–8 秒的平稳句（日文里没有！？…ー～这类感叹、拖音、省略）。按音高、语速离本人中位数的远近排序，音高权重 2，从最近的开始拼，凑够 10 秒、不超过 18 秒。实际每人挑到两句，10–14 秒；拼接时句间 0.35 秒静音，末尾补 0.5 秒（调研笔记 §4.4 的建议）。
- **情绪参考**：种类跟混合版一样。混合版里从同一情绪的原声做出来的，换成同一情绪的原声：这次只有春希的轻声，标签沿用 `moods.label`；锚点用 `moods.pick`，平均向量取标了"轻声"的全部 17 句。从锚点派生的情绪（依绪、武也）和春希的讲述没有原声可对应，落回锚点。
- **质检目标**：音高取锚点片段的中位数；语速沿用混合版的换算（4.2 字/秒 × 本人日语语速 ÷ 几个人的中位数，限制在 3.3–5.0）。算出来和混合版的目标差不多：春希 160Hz、4.03，雪菜 296Hz、3.3，依绪 239Hz、4.37，武也 145Hz、4.66。
- **依绪、武也的逐句门槛**：原来是"和锚点（定妆音）≥0.65"，没法沿用，改成"和本人原声中心比、过音色门槛"，和 evaluate 是同一把尺子。所以这两个人成品的"过门槛"有一部分是门槛本身保证的，比较要看候选级抽查。

**原声不进 git**：`books/wa2/voices/原声.yaml` 只记语音文件名和日文逐字稿。音频在合成时从语音包里现拼，缓存在 `out/rawref/`（不进 git）。

**合成速度**（5090，含重试和质检，小样加〈2002〉合计）：

| | 耗时 ÷ 成品音频 | 每字 | 全书 168 万字 |
|---|---|---|---|
| 混合版 | 2.04 | 0.49 秒 | 9.6 天 |
| 原声平均版 | 2.25 | 0.61 秒 | 11.8 天 |
| 原声向量版 | 2.29 | 0.62 秒 | 12.0 天 |
| 原声版 | 2.52 | 0.64 秒 | 12.4 天 |

- 每字耗时多出来的一部分，来自成品音频变长（语速慢了）。
- 只用说话人向量时提示比混合版短，按理每秒音频不该更慢，原因没查。一种可能是候选的长短差得更大，而一批要等最长的那个生成完。

**06 号票建议的"自动试几种参考码编码"，这里没有做**：原声版已经被口音否掉了；只用说话人向量的版本不经过参考码，编码方式无从谈起。这个建议对仍用定妆音带文本复刻的路线（比如 08 号票）还有意义。

**做了什么**：
- `readbook/rawref.py`（新）：上面的挑选规则。春希的情绪标签缓存在 `out/rawref/春希-labels.json`。`load(版本)` 给出和 `passage.load_voices` 同样形状的参考。
- `readbook/stability.py`（新）：候选级稳定性抽查，结果在 `out/stability/`。
- `readbook/passage.py`：加 `--原声版`、`--原声向量版`、`--原声平均版`，产物在 `out/passage/<名字>-<版本>/`。原声的几个版本里，依绪、武也的门槛改成原声中心。
- `readbook/bakeoff.py`：
  - `TorchQwen.prompt()`：按参考缓存复刻提示；参考带 `xvec` 时走 `x_vector_only_mode`，再带 `spk_files` 时用 `mean_xvec()` 算平均向量；
  - `synth_anchor()`：可以指定门槛的比较对象和下限；
  - `mood_ref()`：没有讲述参考时用锚点。
- 文档：技术报告（迭代表，第二、四、五、六、七、八节）、运行环境（Qwen3 的用法）。

**留给后面的票**：
- **要不要用原声平均版换掉定妆音**：看试听。如果换，术语表里"定妆音""音色锚点"的定义要跟着改：锚点不再是一段中文录音，而是本人原声的平均说话人向量。15 号票写流程规格时定。
- **08 号票（春希只留一个锚点）**：原声平均版里，春希的讲述已经和台词共用一个平均向量，只剩轻声是另一组原声。如果改用原声平均版，08 要验证的就只剩"轻声要不要也并进来"。
- **语速偏慢**：只用说话人向量，就没有参考来带韵律。要不要把语速目标或变速的范围放宽，看试听。
- **情绪**：只用说话人向量时，参考里的情绪也进不来，情绪只能靠别的手段（10 号票 IndexTTS 的情感向量、11 号票的指令）。
- **速度**：全书约 12 天，离一周更远了。
