# 18: 隐去对白的地方留出停顿

Type: prototype（HITL）
Status: resolved
Blocked by: 16

## Question

〈2002〉第 0–19 句是回忆，雪菜一段接一段地打电话。写法上隐去了春希那边的话，只留雪菜这边。现在混音时同一个人连着说两句只隔 0.25 秒（`readbook/mix.py` 的 `GAP`），听起来像她一口气说完。

用户要求：雪菜两段之间加停顿，模拟春希在说话。

做法起点：
- **剧本化时多标一项**：这句前面隐去了别人的话吗，大约要留几秒。她自己接着说的填 0，比如 16→17「那，那个」→「没事，吧？」是她自己在犹豫。换了一通电话、换了场景，可以停得更久。混音照这一项留空。
- **不用固定规则**，比如"同一人连说就拉长"：那样会把她自己接着说的地方也拉开。这几句的效果标的是「回忆」，不是「电话」，靠效果也判断不出来。
- **只补这一项**，剧本里其他字段（类别、情绪、表演提示等）保持不变，免得合成结果跟着变。
- **只重新混音**：16 号票全员版的成品句子还在本机，重新混一遍就行，不用重新合成，也不用 GPU。
- 小样也跑一遍，看有没有在不该停的地方停。

要回答：
- 停顿加在哪几处、各多长、为什么；
- 试听是否自然，像春希在那头说话；
- 这一项怎么并进正式的剧本化流程（普通小说里的单边电话也能用）。

顺手修：对照剧本的时间戳会写出「4:60.0」，是 `passage.write_table` 里秒数四舍五入后没有进位。

## Answer

**剧本化之后单独问一遍停顿，标进剧本的 `pause`，混音照它留空。** 用户试听〈2002〉："自然"。

做法：
- `scriptize.pauses(rows, cast)`：把标好的剧本（idx、类别、说话人、效果、文字）交给 `claude -p`，按 `PAUSE_SCHEMA` 只列出要留白的行，
  给秒数和一句理由（理由只留在试做产物里，不进剧本）。判断标准写在 `PAUSE_RULES`：只看这行和前一行之间有没有别人的话被隐去；
  同一人自己接着说、对白完整的一来一回都不留，拿不准不留；秒数按隐去的话多长估（每秒约 4 字：一两个字约 1 秒，一两句 1.5–3 秒，
  一段 3–4 秒，换一通电话、换场景再加 1–2 秒，最多 6 秒）。
- 单独问一遍，而不是并进剧本化那次调用：已有剧本的其他字段一个不动，合成结果不会跟着变；也能看着标好的说话人来判断。
- `scriptize.with_pauses` 给每行补上 `pause`（秒，这句前面总共留多少空白；没标的填 0）。`mix.gap` 取 `max(原来的间隔, pause)`，
  剧本没有这一项时照旧（同一人 0.25 秒、换人 0.4 秒、旁白前后 0.5 秒）。
- 不重新合成：16 号票全员版的成品句子（`out/index/2.5-原声平均锚点全员/<片段>/wav/`）用 `passage.remix` 重新混音。

结果（明细见 `books/wa2/trials/pauses/停顿表.md`）：
- 〈2002〉标了 11 处，都在第 0–19 句：1→1.5、2→2.5、3→2、5→2、6→3、7→1.5、8→1.5、11→1、13→2、14→2、18→1.5 秒（数字是句号 → 秒数），
  整段加长 17.8 秒。理由都是春希在那头确认、解释、反问，比如第 6 句前的 3 秒是"春希具体讲了将来的规划"。
  3→4、8→9→10、11→12、14→15→16→17、18→19 判为她自己接着说，没留，16→17「那，那个」→「没事，吧？」也在其中。
  没有标出"换了一通电话"的地方，这一档还没在真实片段上用过。
- 小样那 45 句一处没标，和原来的混音一样。剧本 02-2011-01-01 小样以外标了 5 处，都在和纱跟曜子的电话里：16–19 是曜子那头被隐去
  （到第 20 句曜子的话才写出来），41 在曜子沉默之后；45–50 挂了电话后的独白没标，判断对。
- 停顿里是完全的静音，和原来的句间间隔一样，前 0.4 秒是回忆效果的混响尾巴。用户没觉得像断了，所以没加底噪。

怎么并进正式的剧本化流程：
- `passage.load_rows` 新建剧本时已经接上：`scriptize` → `pauses` → `with_pauses` → 写剧本。全书生产照这个顺序，每段剧本多一次 `claude -p`（只发文字）。
- 已有的剧本单独补：照 `readbook.pauses` 的做法，`标注` 出带理由的 json 先看，认可后 `写回`。这次写回了 02-2011-01-01 和〈2002〉两份，
  07-2013-01-26 还没标。
- 普通小说也能用：提示词只用类别、说话人、效果和文字，不靠游戏数据，单边电话、只写一方的对话都适用；盲测模式下先标说话人，再照样问停顿。
- 每段只跑了一次，没测过多跑几次秒数稳不稳。全书生产时如果要更稳，可以跑两三次取中位。

顺手修：
- `passage.write_table` 先把秒数取整到 0.1 秒再拆分钟（`passage.stamp`），不会再写出「4:60.0」；
- 有 `pause` 的句子在对照剧本里标【前停 N 秒】；文件改写成 LF。
- `passage.mix` 现在返回每句的起始秒数，新增 `passage.remix`，只重新混音，不合成：

      uv run python -m readbook.passage remix <片段> <wav 目录> <输出目录> [名字]

重做：

    uv run python -m readbook.pauses 标注   # 写 books/wa2/trials/pauses/<剧本>-停顿.json
    uv run python -m readbook.pauses 混音   # MP3、对照剧本、停顿表.md
    uv run python -m readbook.pauses 写回   # pause 写进 books/wa2/script/*.jsonl

产物在 `books/wa2/trials/pauses/`：〈2002〉和小样的 MP3、对照剧本、停顿表、两份剧本的停顿标注（带理由）。
