# 03: 读音：拼音标注、句首「～」、按拼音评测

Type: prototype（HITL）
Status: open
Blocked by: 01

## Question

按合成规格第五节"文本规范化"和第六节"复核清单"：

- **读音表支持拼音标注**：`books/wa2/lexicon.yaml` 支持 IndexTTS-2.5 的 `<字|拼音声调>` 标注。
  - 写法见 IndexTTS README 的 Pronunciation Control，只有 `checkpoints/pinyin.vocab` 里有的拼音才有效；
  - 先加一条「雪菜」→「`<雪|XUE3>`菜」；
  - 读音表开头那句"模型不支持拼音标注"的注释要改。
- **Qwen3 不认这种标注**：
  - `rawanchor` 生成锚点时，文本也会套读音表；
  - 走 Qwen3 的文本要去掉标注，只留原字，或者按引擎分开处理。
- **字数不算标注**：`qc.SPOKEN` 会把 `XUE3` 算成 4 个字。语速、时长上限、生成上限和字数统计都受影响。
- **句首的「～」**：`synth.tts_text` 去掉句首的「～」，句中的照旧。小样 73 号「～～～呃！？」读出过一个「克」。
- **评测按带声调的拼音比**：
  - `evaluate` 把识别结果和原文都转成带声调的拼音再比，可以用 pypinyin 这类工具；
  - 同音字不算错，「依绪」被识别成「依序」不算；
  - 读音表里标注过的字，原文也按标注注音。
- **复核清单（读音部分）**：挑中的句子按拼音比，错率超过 0.3 就进复核清单。

## 要做的

- **重做相关的句子，给用户试听**：
  - 小样 81「雪菜…」；
  - 〈2002〉40「雪菜她，变了。」、61「…呐，雪菜。」；
  - 小样 73「～～～呃！？」；
  - 以及小样和〈2002〉里其余含「雪菜」的句子，10 号票数过一共 14 处。
- **比较**：看「雪菜」读对的比例，用识别结果加试听。
- **不用修**：「依绪」→「依序」是识别的同音问题，不是读错。
