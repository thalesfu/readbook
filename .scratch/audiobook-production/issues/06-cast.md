# 06: 补齐 cast.yaml

Type: task
Status: resolved
Blocked by: 04

## Question

`books/wa2/cast.yaml` 现在只有 12 个角色：9 个主要角色、3 个龙套。按全书补齐所有开口的角色：

- **档位**：照方案，按合并写法后的台词句数分：主要角色 ≥500 句，配角 30–499 句，龙套不到 30 句。
- **字段**：
  - `tier`、`code`（只填专属编号）、`gender`、`age`、`desc`、`pan`；
  - 声线：有编号的按 04 号票的声线库填，没编号的留给 07 号票。
- **性格卡 `card`**：
  - 孝宏、朋要补上，格式和其他主要角色一样；
  - 配角、龙套用 `desc`。
- **别名**：同一个人的多种写法要合并，比如依绪／依緒、美穰子／美穂子、雪菜母亲／雪菜的母亲、かずさ／和纱。
- **性别、年龄、描述**：可以让 Claude 看剧本起草，用户抽查。
- **`pan`**：主要角色已经有了。新角色的规则这张票定：在 ±0.2 以内，同场出现的角色错开。

## 要定的

**合称的台词**：比如「武也＆依绪」「佐藤＆中川＆春希」「全员」，规格里没写怎么念。

这张票列出全书出现的所有合称和句数，给用户推荐一种念法，由用户定。可选的有：
- 用第一个人的声线；
- 几条声线叠在一起；
- 让主要说话人来念。

## Answer

**定论：[`books/wa2/cast.yaml`](../../../books/wa2/cast.yaml) 补齐到全书 204 个名字：主要 11、配角 26、龙套 147、合称 20。用户抽查"能用"。合称照用户定的「拆开＋叠在一起」。代码在 `readbook/castfill.py`。**

- **数据**：
  - 范围是 `daily.ROUTES` 的剧本，就是每日对话那本书。5xxx、LF3、catch 不在书里，那里只多一个「ほわるば２」；
  - 说话人和语音文件用语音对照表的 CN 部分，有语音的按文件去重，没语音的按行算。日期和台词按 `daily.walk` 现读，和对照表逐行核对一致；
  - 有名字的共 45,502 句。366 行有名字没语音，这些名字在有语音的句子里都出现过，没有只靠没语音开口的角色；
  - 说话人空着或写「？？？」的不进表，剧本化时按编号和上下文认人。
- **档位**：照方案，按合并写法后的全书句数。
  - 主要角色新加朋（571 句）、孝宏（520 句）；
  - 已有的「店员」38 句，按规则算配角，见下面"没改的"。
- **字段**：
  - `code`：只填专属编号，给声线库里这个编号的主角色，一个编号一个角色，共 34 个。因为 `scriptize` 按编号认人（`by_code`），一个编号给两个角色会互相覆盖；
  - `voiceline`（新字段）：41 个。34 个主角色；榛名、雪音、吉田，因为声线名里有自己；女主角１～４，规格第四节写明用千晶的。其余 143 个（龙套 140、配角 3）留给 07 号票；
  - `gender`：按语音编号定。专属编号的按声线库；98 号是女声龙套，99 号是男声龙套（同一个名字「服务生」里，「ウェイトレス」是 98、「ウェイター」是 99）。173 个新名字和起草的全对得上；
  - `age`、`desc`：`claude -p` 看剧本起草，只发台词文字，配角每人 20 句、龙套 8 句，带上下文。起草里的姓名对着剧本原文查过（园田亚子、矢田美穰子、清水早百合、西村和希、雨宫佐和子都查得到）。改了三处，写在 `castfill.DESC_FIX`：
    - 「美穰子的母亲」原来写成"早坂"；
    - 「女子店员１」原来写成中川本人，改成泛称；
    - 一处错字；
  - `card`：孝宏、朋，格式和其他主要角色一样。每人 60 句台词，加上声线库的声优和音高；
  - 已有的 12 个角色只补缺的：9 个主要角色补 `voiceline`；雪菜、和纱、曜子、千晶补别名，和纱的 `[かずさ]` 往后接；别的一个字不动，`write` 里有断言。
- **别名**（`castfill.ALIASES`，在声线库那 7 组之外）：对着日文原名和上下文核对过，同一个人的才合并。
  - **报名字之前的出场**：同一个声优，同一场里接着就叫出名字：
    - 邻座的女生→和纱；和泉→千晶；女生２柳原→朋；
    - 女子学生７→雪菜（「我…无法唱歌」，同伴接着喊"走吧，雪菜！"）；
    - 男子店员１→本田；指导老师→诹访老师（班主任叫他"诹访老师"）；
    - 2001 的男性编辑部员１／２／３、女性编辑部员１→浜田、松冈、木崎、铃木；
  - **日文原名一样，中文没翻译或用了日文字形**：女性記者→女记者、編集長→主编、車内广播→车内广播、男性劆団員４→男性团员４、校長→校长；
  - **日文原名一样，同一场**：空港係員→工作人员、中年男→中年男性、男性录音职员→男性录音室职员、女性录音职员→女性录音室职员；
  - **不合并**：日文原名一样，但出现在不同场景的泛称。比如「男生１／男学生１／男子学生１」分别在序章、小春线、大学，是不同的人；车站的几种广播也不合并。
- **`pan` 规则**（`castfill.pan`）：
  - 新角色从 ±0.05、±0.1、±0.15、±0.2 里挑，不放正中，正中是旁白；
  - **同场**：同一个剧本里两句不同人的台词相隔不到 10 行，记一次；
  - **代价**：同场次数 × max(0, 1 − 两人相差 / 0.1)；
  - **怎么挑**：先按句数从多到少一个个挑，再轮流让每个新角色按其余所有人重挑，直到没人再换。一样轻的挑离正中近的，再挑左边。已有角色不动；
  - **结果**：涉及新角色的同场共 45,808 次，落在同一格的 457 次。错开要求是 0.15 时，同一格的有 1,140 次。剩下的主要是编辑部那一屋：春希、麻理是已有的 -0.1、-0.2，松冈 -0.2，浜田 0.05，铃木 0.2，木崎 0.15；
  - 合称不写 `pan`，各用各的。
- **合称**：全书 20 个名字、27 句。原作每句只有一个语音文件，编号是第一个人的；但 CAM++ 量出来是几个人混在一起录的：2009「春希＆雪菜」离春希中心 0.65、离雪菜 0.64，春希单人的 1–3 秒句离雪菜中位只有 0.37。
  - **各说各的**（3 句）：一句里两段引号，一人一段。2002「武也＆依绪」（11-26）、2009「春希＆雪菜」（12-12）、2312「春希＆小春」；
  - **齐声、点了名的**（13 句）：春希＆和纱、雪菜＆春希 ×3、雪菜母亲＆孝宏、和纱＆春希、佐藤＆中川＆春希、铃木＆松冈、武也＆依绪（2012「干杯！」）、孝宏＆早百合、雪菜＆朋、春希＆雪菜 ×2（3209，那句两段引号一样，算齐声）；
  - **集体**（11 句）：全员、全部人 ×2、全体、小木曽家的众人，多是「干杯」；店员们 ×2、众店员、女店员们、女子店员们、乘客们；
  - **用户定**：拆开＋叠在一起。两段引号的拆成两行，按顺序各念各的；同一句的，每人用自己的声线合成，按各自的 `pan` 叠起来；集体的叠在场开口的 3–4 人，剧本化时按上下文列；路人一起喊、列不出人名的，叠 07 号票配的 3 条龙套声线；
  - **写法**：`tier: 合称`，`combo: [武也, 依绪]`，集体的写 `combo: 在场`，不写性别（录音虽是 98 或 99 号，在场的人男女都有）；
  - **第一段里有 4 句**：11-26「武也＆依绪」要拆开；12-11「店员们」「佐藤＆中川＆春希」「全员」要叠。
- **没改的**（已有角色的字段，按规矩不动，要不要改由协调会话定）：
  - 「店员」：全书 38 句，该算配角（现写龙套）；34 句是 98 号女声，4 句是 99 号，现写男、40 岁。是试做时按 2013-01-26 那一段填的；
  - 工作人员１／２：`pan` ±0.25，超出规格的 ±0.2。
- **给 07 号票**：
  - **对象**：没有 `voiceline` 的 143 个，加上集体合称列不出人名时要的龙套声线；
  - **男女混着的名字**，同名一条声线做不到：店员（98:34／99:4）、客人１（03:15／99:4）、客人２（22:16／99:6）、车站广播（98:13／99:2）、车内广播（99:13／98:1）、站台广播（99:6／98:2）、服务生（98:2／99:2）；
  - **声优兼配的路人**（04 号票留的问题）：剧本里这些句子按 `line_of` 会落到那个声优的声线上。
    - 同一个人、名字整体并不了的（同名在别处是别人）：2002 的「女子学生１」4 句（03 号）是小春初登场，1008 的「女生２」2 句（19 号）是朋，序章的「女性」4 句（16 号）是曜子。这些要按句处理；
    - 真兼配：2015 的客人１（03 号，15 句）、客人２（22 号，16 句），同一天小春、中川也开口；
    - 别的：女子学生１（24 号 1 句）、女子学生２（04 号 2 句、23 号 1 句、19 号 5 句）、女学生２（19 号 1 句）、女生１（25 号 2 句）、男性团员１（28 号 7 句）、男性教师（18 号 2 句，像是诹访老师，没确认）；
    - 大学女生（24 号，16 句，3111）：起草说是孝宏的女朋友，声优是亚子的，没确认是不是亚子。
- **给 08 号票和合成**：
  - **`scriptize` 按编号改说话人是无条件的**：榛名（04）会变成千晶，丢掉自己那条声线；吉田（28）会变成和希；客人１（03）会变成小春；女主角１～４会变成千晶。建议：给了名字、名字在角色表里的照原名；只有空着和「？？？」才按编号认。02 号票没动这块；
  - **`scriptize` 不认 `aliases`**：写法不同的名字要先换成主写法，否则报"不在角色表里"；
  - **提示变长**：`cast_text` 现在把 204 个名字的描述全放进剧本化和停顿的提示，约 1.1 万字。建议只列当天出场的加主要角色；
  - **合称要接进流程**：剧本化要把两段引号的拆成两行，集体的列出在场的人；合成要每人各生成一遍、各过各的门槛；混音要按各自的 `pan` 叠。现在都还不支持。`mix` 和 `index_passage` 取 `pan` 用 `.get(…, 0)`，叠音做好之前合称会落在正中。
- **成本**：`claude -p` 11 次（9 批描述、2 张卡），共约 $4.45，每次 9–57 秒，4 路并行。
- **GPU**：没用。CAM++ 看合称录音那 17 个文件是在 CPU 上跑的。
- **用法**：
  - `uv run python -m readbook.castfill count`：数说话人，打印合称；
  - `uv run python -m readbook.castfill draft`：起草，缓存在 `out/castfill/`，不进 git；重跑只补没做的；
  - `uv run python -m readbook.castfill write`：写进 `cast.yaml`。已经在表里的只补缺的字段，所以重跑不改任何东西；剧本里出了新名字，重跑就只接上新的。
