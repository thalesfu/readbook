# 07: 没编号的角色分声线

Type: prototype（HITL）
Status: resolved
Blocked by: 05, 06

## Question

按合成规格第四节"角色怎么分到声线"，按全书做：

- **对象**：`cast.yaml` 里没有专属编号的配角和龙套，包括 98、99 号。
- **主要角色的声线不借出去。**
- **由 Claude 挑**：按性别、年龄、描述，从其余声线里挑。每条声线附上性别、音高中位（从原声量出来的）和角色描述。
- **硬约束，由程序检查，不靠 Claude**：
  - 这个角色开口的每一天，都不能有同一个声优配的角色也开口；
  - 同一个声优的不同声线也算在内；
  - "同一天"按游戏的日期来切，和每日对话、剧本文件的切法一致。
- **同一个名字全书固定一条声线。**
- **缺口清单**：分不到的列出来，交给外来声线专项。

## 要做的

- **分配表给用户看**：每个角色列出出场天数、句数、分到的声线和理由。
- **第一段里的例子**：男子学生１～６、店长、干事、店员、车内广播等，都是 98、99 号。

## Answer

**定论：`books/wa2/cast.yaml` 里 141 个没编号的角色、8 个集体合称都分到了声线（新加 `voiceline` 149 个），缺口清单是空的；硬约束按写好的 `cast.yaml` 查过 0 处违反，只有 12-11 的男子学生４～６ 是用户定的例外。分配表在 [`books/wa2/voices/分配.md`](../../../books/wa2/voices/分配.md)，用户看过："能用"。代码 `readbook/assign.py`。**

- **对象**：
  - 06 号票留下 143 个没有 `voiceline` 的：女子学生２、男性教师的句子核对下来全是有编号角色本人，不分；其余 141 个都分了；
  - 集体合称：剧本化列不出人名、退回"路人"时用，每个配 3 条。全员、全部人、全体一般列得出在场的人，也配上，备着。小木曽家的众人是有名有姓的一家人，不配路人的声音。共 8 个。
- **能借的声线**：23 条。35 条里，主要角色的声优那 12 条不借；榛名是千晶的声优演的，也算在里面。
- **兼配核对**（泛称的台词、录音却是有编号的声优，`assign.SAME_PERSON`）：对着上下文看，15 处里 14 处就是那个角色本人，这几句按本人算——念、数句数、查撞声都算本人：
  - 女子学生１：03 号 → 小春（2002「是北原春希吧？」，第一段 11-26）；24 号 → 亚子；
  - 女子学生２：23 号 → 早百合（2003，小春接着说"早安，早百合、亚子"，第一段 12-01）；04 号 → 千晶；19 号 → 朋；
  - 女学生２、女生２：19 号 → 朋；女生１：25 号 → 美穰子；女性：16 号 → 曜子；
  - 客人１：03 号 → 小春；客人２：22 号 → 中川。2015 值早班的两人下班后坐下来挖苦"啰嗦的指导员"，06 号票当成了真兼配；
  - 女子店员１：22 号 → 中川（2005，第一段 12-05）；男性团员１：28 号 → 吉田（2406 摔门不演，2407 团长叫"吉田"）；男性教师：18 号 → 诹访老师；
  - **真兼配只有大学女生**（3111 孝宏的女朋友，"不知不觉已经过去四年了"，不是亚子）：照原作用亚子的声线，那天亚子不出场（用户选了推荐项"照原作用亚子的"）。
- **没报名字的 98、99 号**（`assign.UNNAMED_IS`）：
  - 2005#9 是店长（第一段 12-05 打来电话，接着说店长扭了腰）；
  - 2029#696 是 ＤＪ；
  - 另外 5 句认不出是谁，不算：1004、1008 两句是旁白带了语音，2316 是杉浦家接电话的，3102 两句是机场喊"冬马"的男人。剧本化认出来要是新名字，得补分。
- **性别**：按除去本人那几句后剩下的录音，98 女、99 男。
  - 男女都有的 5 个按多的配一条（用户选了推荐项"按多的配一条"）：店员 34 女／4 男、车站广播 13／2、车内广播 1／13、站台广播 2／6；服务生 2／2 平手，按表上的女。少数这边的 11 句换了性别，都是广播和客套话；
  - 和 `cast.yaml` 写的性别对不上的 3 个，表上的字段没动：店员（表上写男、40 岁，配了美代子的女声）、客人１、客人２（表上写女，剩下的是男客人，配了吉田、松冈）。
- **一天**：照 `daily.py` 的切法，路线不同算不同的天，序章一个剧本算一天。2029 里写成"201 年"的，按 2011 年算。
- **Claude 排**（`claude -p`，只发文字）：
  - 每条声线给性别、音高中位、原声句数、声线名里角色的描述，锚点没过门槛的注明；每个角色给按录音定的性别、年龄、描述、句数、天数、4 句台词；
  - Claude 把同性别能借的声线分成"合适""勉强"排好先后，不合适的不列；
  - 第一轮 9 批；挑不上的 5 个再问一轮，只给那几天没人用的声线：女学生６ 补上铃木、男生３ 补上木崎，12-11 的男子学生４～６ 那天只剩诹访老师、浜田，Claude 说年纪不对；
  - 共约 $4.68。
- **怎么挑**（程序）：
  - 句数多的先挑，挑排得最前、和同天已定的不撞声优的那条；
  - 挑不到的，让撞了的同天角色连着往后换，最多 3 层，不换出新缺口；补完后排在前面的又空出来了就换回去；
  - 角色都定了再挑群声：Claude 列的排完接上其余能借的，男女都要有，凑不齐用剩下的补满。群声之间不查撞声，都是路人，同一天的「女店员们」「女子店员们」就是同一群人。
- **硬约束**（`assign.violations`，按 `cast.yaml` 现查：`uv run python -m readbook.assign check`）：
  - 每个角色开口的每一天，没有同一个声优配的别的角色开口，同一个声优的不同声线也算（佐藤、高柳）；
  - 结果 0 处。
- **12-11 的例外**（用户选了推荐项"借同场男生的声线"）：
  - 联谊会开在春希打工的餐厅，一整天一场。男声龙套 11 个，能借的男声优 12 个，佐藤、本田当天开口，剩 10 个；年轻的只有 5 个，年轻角色 8 个；
  - 补缺口连着换了几层以后，干事、男子店员３ 分到了，剩男子学生４～６（共 4 句）；
  - 各借一条同场男生的，连着的三句各用一条不同的，都对得上借出的人自己的台词：
    - 男子学生４「要接着去卡拉ＯＫ唱歌的人～」借男子学生１（亲志）的，他接着就拉雪菜去唱卡拉ＯＫ；
    - 男子学生５「要留在这里喝酒的人～」借男子学生２（上原）的，他接着说要留下喝酒；
    - 男子学生６「出租车来了哦」借干事（吉田）的。
  - 写在 `assign.BORROW`，外来声线到了可以换掉。
- **数据**：
  - 141 个角色、全书 1,059 句。除去原作 1 个、例外 3 个，137 个里拿到 Claude 排第 1 的 80 个，第 2 的 26 个，第 3 的 21 个，第 4–5 的 10 个；
  - 评"合适"的 115 个，"勉强"的 22 个（2 个是第二轮的）；
  - **第一段**：出场的龙套 17 个，加全员、店员们两个群声。"勉强"的 4 个都因为 12-11 年轻男声挤：男子学生２ 上原（偏温厚）、男子学生３ 木崎（偏成熟）、店长 班主任（原声少，有教师腔）、车内广播 领队；
  - **借得最多的**（含群声）：美代子 16、亚子 14、铃木 14、上原 13、松冈 11，都在不同的天；班主任、26 号、浜田、高柳各 2；
  - **26 号**（锚点没过门槛）借给了电话留言、手机提示音，共 11 句，Claude 评的是"勉强"，生产时多看复核清单。
- **缺口清单**：空的。没有交给外来声线专项的。
- **`cast.yaml` 怎么改的**：
  - 只加 `voiceline`：角色写一条，放在 `code` 后面，没有 `code` 的放在 `tier` 后面；群声写 3 条的列表；
  - 别的字段、名字、顺序一个没动，`write` 里有断言；文件头 `voiceline` 的说明补了一句；
  - 重跑 `write` 只更新这张票写的 `voiceline`。
- **用法**：`uv run python -m readbook.assign count | rank | rank_gaps | solve | write | check`。
  - Claude 的排序缓存在 `out/assign/rank-*.json`，不进 git；
  - 分配表由 `write` 生成。
- **给 08 号票（剧本化）**：
  - `scriptize.given` 把"名字和编号主角色对不上"的交给 LLM 选。全书的标准答案在 `assign.SAME_PERSON`（按本人）和 `assign.OWN_ACTOR`（大学女生要保持大学女生，不能认成亚子），可以直接用，不用 LLM 猜；
  - 第一段里有：11-26 女子学生１（03）→ 小春；12-01 女子学生１（24）→ 亚子、女子学生２（23）→ 早百合；12-05 女子店员１（22）→ 中川；
  - 12-05 的 2005#9「？？？」（99 号）是店长；
  - 集体合称退回"路人"时，用这个合称在 `cast.yaml` 里的 3 条 `voiceline`。
- **给协调会话**（按规矩没动的）：
  - `cast.yaml` 里店员（男、40 岁、演出场地男店员的描述）、客人１／２（女、女客人的描述）的 `gender`、`desc` 和实际录音对不上，可以改成泛称的女店员、男客人；
  - 合成规格第四节写的是"每一章"，这张票按票里写的"每一天"做；兼配按本人、男女混着按多的、群声、例外，可以补进规格。
