# 小说转有声书运行环境

主机是 Windows 11 上的 RTX 5090 笔记本（24GB），合成、训练、评测都在这台上跑。Mac 上的 MLX 代码只作参考。搭建记录见 `.scratch/voice-pipeline/issues/01-windows-env.md`。

## 装了什么

| 组件 | 版本 | 怎么装的 |
|---|---|---|
| 显卡驱动 | 610.88，最高支持 CUDA 13.3 | 机器自带 |
| uv | 0.12.19 | winget |
| Python | 3.12.14 | uv 自己下载（`.python-version`） |
| PyTorch / torchaudio | 2.11.0+cu128 | `uv sync`；`pyproject.toml` 按平台区分，Windows 从 PyTorch 的 cu128 源安装，Mac 装 mlx-audio |
| ffmpeg | 9.0.2 | `winget install --id Gyan.FFmpeg -e --source winget --scope user` |
| Claude Code | 2.1.311 | 官方安装脚本 `irm https://claude.ai/install.ps1 \| iex`，装到 `~/.local/bin`，第一次用要先在终端里登录 |
| funasr / transformers | 1.4.16 / 4.57.3 | `uv sync`，只在 Windows 上装：评测用的 CAM++、emotion2vec+ 走 funasr，Whisper 走 transformers（05 号票） |
| qwen-tts | 0.1.1 | `uv sync`，只在 Windows 上装：官方 PyTorch 版 Qwen3-TTS（06 号票）。它把 transformers 钉在 4.57.3、huggingface_hub 要 <1.0，所以 Windows 上这两个比 Mac 低（Mac 仍是 5.20.2 / 2.3.0）；降级后 Mac 基线 MP3 的评测结果逐句不变 |

- **不装 CUDA Toolkit**：cu128 的轮子自带运行库。
- **不装 flash-attn**：Windows 上没有预编译轮子，Qwen3-TTS 默认就用 sdpa（见 `research/qwen3-torch` 的调研笔记）。
- **没用 cu130**：驱动其实已经支持 CUDA 13。没用它，是为了让各个环境都对齐 cu128。
- **CAM++ 不再依赖 IndexTTS2**：Windows 上 readbook 自己的环境就有 PyTorch，`readbook/speaker.py` 在本进程里用 GPU 算，权重和 IndexTTS2 用的是同一份。Mac 上还是走 IndexTTS2 环境的子进程。

## 模型

HuggingFace 上的模型都放在默认缓存 `~/.cache/huggingface/hub`。`readbook/config.py` 默认把 `HF_ENDPOINT` 设成 hf-mirror、关掉 xet；代码里用 `config.hf_model()` 取模型，缓存里有就不联网。大模型要提前在后台下：

```
HF_ENDPOINT=https://hf-mirror.com HF_HUB_DISABLE_XET=1 uvx --from huggingface_hub hf download <仓库> [文件…]
```

| 模型 | 仓库 | 大小 | 用途 |
|---|---|---|---|
| CAM++ | `funasr/campplus`（`campplus_cn_common.bin`） | 28MB | 声纹相似度、认人 |
| Whisper large-v3-turbo | `openai/whisper-large-v3-turbo` | 1.6GB | 识别字错率 |
| emotion2vec+ large | `emotion2vec/emotion2vec_plus_large` | 1.9GB | 情感分类（9 类） |
| Qwen3-TTS 1.7B Base | `Qwen/Qwen3-TTS-12Hz-1.7B-Base` | 4.5GB | 逐句合成（带文本复刻），见 `bakeoff.TorchQwen` |

Qwen3-TTS 的用法（06 号票实测，对齐 Mac 上的 mlx-audio 0.6.1）：
- 主模型 bf16、sdpa，不装 flash-attn；**语音编码器（`speech_tokenizer/`）要按存储的 fp32 单独加载**：`from_pretrained(dtype=bf16)` 会把它一起转成 bf16，mlx-audio 不转，bf16 下雪菜的音色明显更容易跑偏；
- 非流式（`non_streaming_mode=True`）、子 talker 和主 talker 同一个温度、重复惩罚 1.5 只罚最近 64 个首码本 token（包一层 `talker.generate`）；
- 一句的几个候选当一批生成：batch=5 的耗时只比 batch=1 多一成左右，显存峰值约 6GB；
- `import qwen_tts` 时报的 flash-attn、SoX 警告可以不管，12Hz 模型用不到。

## 这台机器上的坑

- **Norton 换证书**：Norton 的加密连接扫描会把所有 HTTPS 证书换成它自己签的。处理办法是每个环境各自改用 Windows 证书库，Norton 本身不动：
  - uv：`%APPDATA%\uv\uv.toml` 里写 `system-certs = true`；
  - Python：requests、httpx 默认只认 certifi，会报 `CERTIFICATE_VERIFY_FAILED`。readbook 在 `config.py` 里调用 `truststore.inject_into_ssl()`（只在 Windows 上），所有 readbook 模块一导入就生效；
  - **pip-system-certs 和新版 huggingface_hub 冲突**：pip-system-certs 注入的是 pip 自带的那份 truststore；huggingface_hub 2.x 改用 httpx2，它自己又用独立安装的 truststore，两份叠在一起，一联网就 `RecursionError`。所以 readbook 在 05 号票里把 pip-system-certs 换成了上面的做法。**以后装 IndexTTS2、Applio 的环境**：huggingface_hub 还是老版（用 requests）的，可以照旧加 pip-system-certs；是 2.x 的，就在入口调用 `truststore.inject_into_ssl()`；
  - winget：msstore 源会因为证书不匹配而失败，所以装软件时要加 `--source winget`；
  - `uvx hf download` 什么都不用加：huggingface_hub 2.x 自己就用 truststore 读 Windows 证书库；加了 `--with pip-system-certs` 反而会递归。
- **网速**：大约 0.8 MB/s。清华 PyPI 镜像、PyTorch 官方源、南大镜像、hf-mirror 都差不多，走本机代理（7897）也不会更快。torch 的轮子有 2.75 GB，下载要一小时左右。
- **编码**：Windows 上 `subprocess` 的 `text=True` 和管道输出默认都是 GBK。凡是和子进程交换文本（`claude -p`、CAM++ 子进程）或者往管道里输出 jsonl 的地方，都要显式写 `encoding="utf-8"`。
- **临时文件**：`NamedTemporaryFile` 打开期间，别的进程读不到它。要加 `delete_on_close=False`，先关掉再交给别的进程。
- **PATH**：ffmpeg、claude 装好后，要新开终端或者重启 Claude 桌面应用，才能在 PATH 里找到它们。

## 验证

```
uv sync
uv run python -m readbook.wa2 "01 第二部-共通" 2010-11-25 > day.jsonl   # 156 行，sid ≥ 2002 的 65 句就是〈2002〉
uv run python -m readbook.voices 2002_0000_02.OGG                      # 导出到 out/voice/
```

2026-10-27 实测结果：
- **GPU**：`torch.cuda.is_available()` 为真，设备是 RTX 5090 Laptop，算力 (12, 0)，显存 23.9GB。bf16 的 8192² 矩阵乘大约 54 TFLOPS。sdpa 和 torchaudio 重采样在 GPU 上都能跑。
- **数据**：〈2002〉取出 65 句，语音文件名和中文都和 `books/wa2/script/2010-11-25 〈2002〉.jsonl` 逐句一致。读取一天的数据不到 1 秒，建语音索引（46005 条）0.1 秒。
- **剧本化**：`claude -p --output-format json --json-schema ...` 在 Windows 上正常返回 `structured_output`，输入里的中文和"♪"都没问题。
- **模块**：`readbook/` 下所有模块在 Windows 上都能导入。MLX 只在函数内部导入。Qwen3-TTS 逐句合成在 06 号票里换成了 PyTorch 版（`passage.py`、`bakeoff.py` 的 synth / synth-anchor 按平台分支）；生成定妆音用的 VoxCPM2 路径（`bakeoff.py` 的 prepare / moods-build / anchors / derive，`synth.py`）仍然只能在 Mac 上跑。
- **合成**（06 号票）：`uv run python -m readbook.passage 小样`、`uv run python -m readbook.passage "2010-11-25 〈2002〉"`，产物在 `out/passage/<名字>/`。
