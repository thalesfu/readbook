# 小说转有声书商用对照：豆包语音合成 2.0

14 号票。用火山引擎豆包语音合成 2.0 的**预置音色**做小样和〈2002〉，和本地方案对照，作为"放开开源限制"时能到什么程度的参考。没有开通音色设计，也没有做声音复刻：发给豆包的只有文字，声优原声没出本机。

代码：`readbook/volc.py`（接口和计费记账）、`readbook/volc_passage.py`（试音、情绪实测、整段）。

豆包的〈2002〉带 18 号票的停顿（隐去对白处留 1–3 秒），所以比另外两版长 18 秒左右；逐句内容不受影响。

## 配置

| 角色 | 音色 | speech_rate | 怎么定的 |
|---|---|---|---|
| 春希（台词、旁白、心里话） | 儒雅逸辰 `zh_male_ruyayichen_uranus_bigtts` | +30 | 用户听试音选的 |
| 雪菜 | 甜美桃子 `zh_female_tianmeitaozi_uranus_bigtts` | −15 | 同上 |
| 依绪 | 直率英子 `zh_female_zhishuaiyingzi_uranus_bigtts` | 0 | 同上 |
| 武也 | 小天 `zh_male_taocheng_uranus_bigtts` | −25 | 同上 |

- **情绪**：每句的语音指令（`additions.context_texts`，不计费）＝剧本情绪的描述（`moods.HINT`）＋剧本的表演提示（`instruct`），例如"难过，声音低沉无力，颤着声音追问自己"。春希情绪平常的旁白和心里话给讲述的提示。情绪实测里试了 5–8 种做法，用户听着这种最好。
- **没用的参数**：
  - `audio_params.emotion`：在 2.0 音色上乱写一个值也不报错，听不出效果，像是被忽略了；
  - `loudness_rate`：确实能调音量，但混音时每句都会先拉到同一响度，调了等于没调；
  - 表现力增强版 `seed-tts-2.0-expressive`：普通音色也能用，用户听情绪实测后没选。
- **语速**：每个角色一个 `speech_rate`，把试音时的语速拉到定妆音的目标语速，取 5 的倍数，不再后期变速。
- **混音**：和本地版同一套（`passage.mix`）：心里话加混响、压低，旁白干声，台词加房间感和声像。
- **音色区分**：四个音色两两的 CAM++ 相似度都 ≤0.44（本人原声最像的一对是雪菜和依绪，0.53），听得出谁在说。

## 指标对照

三版都用同一个评测（`readbook.evaluate`），都是从混好的 MP3 切回逐句算的。**像锚点**是和各自音色锚点的 CAM++ 相似度，用来看前后稳不稳：豆包的锚点是每个音色不加指令、说一遍自己定妆音的文字（`books/wa2/trials/volc/锚点/指令+情绪/`）；IndexTTS 全员版用原声平均锚点；混合版用定妆音。锚点各不相同，所以这一项只说明每版**自己前后一致到什么程度**。像原声不比：预置音色本来就不是本人（豆包四人和本人原声中心只有 0.1–0.4）。

| 小样 | 像锚点 中位（最低），≥1.5 秒 | 0.74（0.65） | 0.83（0.67） | 0.76（0.10） |
| 小样 | 认人·锚点（全部句子） | 43/43 | 43/43 | 34/43 |
| 小样 | 字错率 中位 / >0.3 的句数 | 0.000 / 3 | 0.018 / 4 | 0.000 / 2 |
| 〈2002〉 | 像锚点 中位（最低），≥1.5 秒 | 0.74（0.41） | 0.84（0.58） | 0.60（0.16） |
| 〈2002〉 | 认人·锚点（全部句子） | 58/58 | 58/58 | 46/58 |

数字说明：

- **认人**：豆包两段全部认对（101/101），和 IndexTTS 全员版一样，比混合版好。四个音色本身差得远，不容易混。
- **前后稳定**：豆包每个人前后的音色一致，像锚点中位 0.74，比 IndexTTS 全员版的 0.83 低一些。但豆包的锚点不加指令，整段每句都带情绪指令，这一项有一部分是情绪带来的变化，不全是音色漂移。没有混合版那种掉到 0.1 的句子。最低的是〈2002〉雪菜"那，那个"（0.41，1.55 秒，接近短句）。
- **春希的音高**：儒雅逸辰比春希的定妆音低了大半个八度（约 100 Hz 对 158 Hz），是"更成熟、更低沉"的春希。评测里春希几乎每句都标了"句内变调"（最高一段到了 400 Hz 的上限），这个音色低、带点气泡音，估音高时容易跳八度，多半是误报，要靠耳朵确认。
- **雪菜的语速**：〈2002〉里雪菜只有 2.6 字/秒，比目标 3.47 慢不少。这一段雪菜多是轻声、难过、停顿后低声说，指令本身就让她慢下来，−15 又压了一道。小样里是 3.5，正好。
- **读音**：字错率 >0.3 的句子都是两三个字的短句。识别出来的人名错字基本都是同音字：依绪写成"一许/依序"，春希写成"春夕"。可能真读错、要听一下的有这几处：
  - 〈2002〉3:59.5 #44、4:22.0 #47：雪菜被识别成"血菜"（xuè）；
  - 〈2002〉2:21.0 #23：令人作呕被识别成"作伴"；
  - 〈2002〉3:42.5 #40：雪菜她被识别成"雪菜糖"；
  - 小样 2:08.6 #76：震惊被识别成"落千整"；
  - 小样 0:39.5 #10：开头的"………"多读出一个音（识别成"其实是"），情绪实测里也见过。

## 速度和费用

| | 豆包 2.0 | IndexTTS-2.5 全员版 | 混合版-5090 |
|---|---|---|---|
| 每字耗时 | 0.075 秒（请求耗时，含网络；实时率 0.30） | 0.321 秒（只算用到的候选） | 0.49 秒（含重试和质检） |
| 全书（168 万字口径） | 单连接串行约 35 小时（1.5 天） | 约 7.5 天 | 约 9.6 天 |
| 占本机 GPU | 不占 | 占 | 占 |
| 费用 | 0.0003 元/字 | 电费 | 电费 |

- 每字耗时按发音字数算，和本地版同一口径。小样 0.084 秒，〈2002〉0.071 秒。并发上限没测；如果平台允许并发，耗时还能按并发数缩短。
- **计费**：豆包按送去的文字全长计费，标点、引号都算（小样计费 682 字，正好等于送去的文字总长）。全书剧本按游戏里所有路线实数：154.1 万字（含标点），发音字 125.2 万字。所以全书约 154 万 × 0.0003 ≈ **462 元**，按 168 万口径是 504 元。重做的句子另算钱。
- **本票用量**：一共 4,422 字（试音 824、情绪实测 1,354、锚点 217、两段整段 2,003、冒烟和参数探测 24），加上 13 号票的 34 字，合计 4,456 字。还在 2 万字的免费额度里，没花钱。每次请求都记在 `out/volc/usage.jsonl`，`uv run python -m readbook.volc 用量` 汇总。

## 要不要开通音色设计

先不开。理由：

- 这张票要回答的是稳定性和情绪的上限。这两点预置音色已经能看出来：认人全对，前后一致，情绪靠语音指令。音色设计改变的主要是音色像不像，管不了稳不稳。
- 预置音色最大的差距是像不像本人。例如春希比定妆音低了大半个八度。音色设计用文字描述（年龄、音高、气质）造音色，不用传原声，不违反"原声不出本机"，能补这一点。但它另外收费，造出来的音色也不会是声优本人。
- 所以只有一种情况值得开：试听后决定拿豆包做正式方案，而且主要不满意的是音色不贴角色。到那时再开，先给春希做一个。

试听后不拿豆包做正式方案，所以不开。

## 试听结论

用户 2026-10-29 试听两段，原话：「我觉得听上去不是很好，还不如我们自己做的，如果再调教还要花token，我觉得暂时就算了」。

- **定论**：豆包 2.0 预置音色听感不如本地的 IndexTTS-2.5 全员版。暂停，不再调。
- 指标上豆包不差：认人全对，字错率低，前后也稳。但试听不如本地，说明这几项指标反映不出听感上的差距。
- 以后要是再试，先处理春希音色太低、〈2002〉雪菜太慢这两点。两段整段一次约 2,000 字；免费额度还剩 15,544 字，用完后每次约 0.6 元。
