# 小说转有声书合成规格

正式合成流程的规格，写清楚这几件事：
- 用哪些模型、怎么串起来；
- 每一步的参数；
- 质检门槛和重试；
- 实测速度和全书预估。

它是 voice-pipeline 地图的终点：15 号票，2026-10-30 和用户逐条定下。

- 为什么这么定：见各票的 Answer（`.scratch/voice-pipeline/issues/`）和 [小说转有声书方案](小说转有声书方案.md)；
- 术语：见仓库根目录的 `GLOSSARY.md`；
- 环境：见 [小说转有声书运行环境](小说转有声书运行环境.md)。

标了"（生产前验证）"的条目已经定了，但还没合成试听过。全书开跑前，先在小样和〈2002〉上听一遍。

## 一、验收标准

- **试听为准**：
  - 同一角色前后不像换了人；
  - 分得清谁在说；
  - 旁白和台词分得开；
  - 语气大体贴性格。
- **门槛**：
  - 每句过音色门槛（只算去掉首尾静音后 ≥1.5 秒的句子）；
  - 认人准确率 ≥95%。
- **现状**：11 号票定版（`2.5-表演B混音`），从 MP3 测：
  - 过音色门槛：小样 30/32，〈2002〉51/51；
  - 认人：100%；
  - 用户试听认可。

## 二、流水线

| # | 环节 | 做法 | 代码 | 出处 |
|---|---|---|---|---|
| 1 | 取文本 | 《白色相簿2》直接读游戏剧本数据（说话人、语音文件、日文原文）；普通小说走 epub 解析 | `wa2.py` | 方案 |
| 2 | 剧本化 | `claude -p` 给每句标类别、说话人、声音效果、情绪、表演提示 | `scriptize.scriptize` | 方案 |
| 3 | 停顿 | 剧本化之后单独一遍 `claude -p`，标出隐去对白的地方要留几秒 | `scriptize.pauses` | 18 |
| 4 | 表演设置 | 再单独一遍 `claude -p`，逐句给情感向量、语速倍数、音量 | `perform.label` | 11 |
| 5 | 声线和音色锚点 | 建声线库；每条声线用原声的平均说话人向量复刻一段中文音色锚点 | `rawref`、`rawanchor` | 16、17、15 |
| 6 | 逐句合成 | IndexTTS-2.5：说话人参考用音色锚点；情绪用情感向量，讲述模式用讲述定妆音；候选按轮生成 | `index_passage`、`indextts_batch` | 10、16、11、15 |
| 7 | 挑选和质检 | 音色门槛加音高、语速、时长、句内变调；过关就停；不过就补轮次；兜底的记进复核清单 | `index_passage.pick`、`bakeoff.ok`、`bakeoff.finish` | 17、15 |
| 8 | 混音 | soxr 转 48 kHz，然后削高频、拉平响度、加效果、立体声定位、留停顿、加减音量 | `voices.to48k`、`mix` | 18、19、11 |
| 9 | 输出 | 每章一个 MP3，附对照剧本和复核清单 | `mix.to_mp3`、`passage.write_table` | 方案、15 |

**隐私和文件**：
- 第 2–4 步只把文字发给 `claude -p`；
- 原声只在本机处理，不上传任何云服务，也不进 git；
- Obsidian 里的原文只读，不改。

## 三、剧本

### 字段

剧本文件在 `books/wa2/script/<剧本>.jsonl`，一行一句：

| 字段 | 来自 | 说明 |
|---|---|---|
| `idx`、`text`、`voice`、`jp` | 游戏数据 | 序号、中文、语音文件、日文 |
| `type`、`speaker`、`effect`、`mood`、`instruct` | 剧本化 | 类别、说话人、声音效果、情绪（10 类）、表演提示 |
| `pause` | 停顿那一遍 | 这句前面留几秒空白，没有的填 0 |
| `perform` | 表演设置那一遍 | `{vec, tempo, gain}`，见下 |

- **每一遍只加自己的字段**：已有字段一个不动。哪一遍要重标，就把它那一项整个换掉。
- **缺字段按默认值**：
  - 没有 `pause` 按 0；
  - 没有 `perform` 时，情绪按 `mood` 查 `index_passage.EMOTION`，语速 1，音量 0。旧剧本照样能跑。
- **顺序**：剧本化 → 停顿 → 表演设置 → 写剧本，每段剧本调三次 `claude -p`。
  - `passage.load_rows` 新建剧本时三步都接上了：停顿是 18 号票，表演设置是生产 02 号票；
  - 已有剧本用 `readbook.perform 标注` 先看，认可了再 `写回`。

### 停顿（18 号票）

- **输入**：`scriptize.pauses` 把标好的剧本（idx、类别、说话人、效果、文字）交给 `claude -p`，只列要留白的行。
- **判断**：只看这一行和前一行之间，有没有别人的话被隐去。
  - 同一个人自己接着说、对白完整的一来一回，都不留；
  - 拿不准的不留。
- **秒数**：按被隐去的话大约多长来估，每秒约 4 字：
  - 一两个字约 1 秒；
  - 一两句 1.5–3 秒；
  - 一段 3–4 秒；
  - 中间换了一通电话或换了场景，再加 1–2 秒；
  - 最多 6 秒，保留一位小数。
- **混音**：句间间隔取原来的间隔和 `pause` 里大的那个。

### 表演设置（11 号票）

- **调用**：`perform.label` 一段剧本调一次 `claude -p`。提示里有：
  - 出场人物的性格卡（`cast.yaml` 的 `card`，没有卡的用 `desc`）；
  - 整段剧本和已有字段；
  - 情绪查表值；
  - 引擎的限制：宁淡勿浓，情感向量总和会被压到 0.8 以内。
- **正式只要三个字段**（试做时要了七个）：

| 字段 | 范围 | 用在哪 |
|---|---|---|
| `vec` | 8 维，每维 0–1：喜、怒、哀、惧、厌恶、忧郁、惊讶、平静 | 合成：代替按 `mood` 查表，照旧过 `normalize_emo_vec`；全 0 表示不加向量，就是本人平常的声音 |
| `tempo` | 0.5–1.25 | 挑选前先用 atempo 变速；挑选时目标语速乘它，时长上限除以它 |
| `gain` | −9 到 +3 dB | 混音：每句先拉平响度、过完后期链，再加减这个值 |

- **讲述模式的行**（叙述者情绪平常的旁白和心理活动）：
  - `vec` 填 0，照旧用讲述定妆音；
  - 只看 `tempo` 和 `gain`。
- **`mood` 和 `instruct` 还要留着**：
  - `mood` 用来判断讲述模式，没有 `perform` 时也靠它查表；
  - `instruct` 只给表演设置那一遍当参考。
- **所有角色都给表演设置**：不再按配角、龙套限制情绪种类。以前限制，是因为每种情绪都要单独做一段定妆音。
- **模型**：Opus 5.5，这是 11 号票验证时用的。换模型要重新试听。

## 四、声线和音色锚点

### 声线库

- **声优和声线**：
  - 声优是真人；
  - 声线是一个声优的一种分得开的声音，记作「声优名-角色1，角色2…」；
  - 音色锚点、音色门槛、质检目标都按声线算。
- **原作声线**：语音编号是按声优分的。同一个编号下的每个角色，先各算一条声线：
  - **合并**：两条声线的原声互相认人（每句原声离哪条声线的原声中心更近），准确率低于 90% 就列出来，用户听过再决定合不合并。真不同的角色，这个数是 96–99.7%。
  - **原声太少就用主角色的**：一个角色在这个编号下可用原声不到 20 句，撑不起自己的声线，就用这个编号下台词最多的那个角色的声线。
  - **例子**：04 号千晶 2446 句。她在千晶线舞台剧里演的雪音 96 句、榛名 66 句，各自试一条声线；剧本 2405 的「女主角１～４」各 4–6 句，用千晶的声线。
- **外来声线**：别的游戏、影片的声优另开专项，见第十节。
- **已查到的原作声优**：

  | 角色 | 声优 |
  |---|---|
  | 春希 | 水島大宙 |
  | 雪菜 | 米澤円 |
  | 和纱 | 生天目仁美 |
  | 麻理 | 浅川悠 |
  | 武也 | 寺島拓篤 |
  | 依绪 | 中上育実 |

  其余的和全书声线见声线库 `books/wa2/voices/声线.yaml`（生产 04 号票，`readbook/voicelines.py`）。

### 角色怎么分到声线

- **有自己语音编号的角色**：用自己的声线。
- **没有编号的配角、龙套**：包括 98、99 这两个多人共用的编号，它们的原声混着好几个声优，做不成声线。
  - 主要角色的声线不借出去；
  - 由 Claude 按性别、年龄和角色描述，从其余声线里挑。每条声线附上从原声量出的性别、音高和角色描述；
  - **硬约束**：这个角色开口的每一章里，都不能有同一个声优配的角色也开口。同一个声优的不同声线也算在内。这一条由程序按剧本检查；
  - 同一个名字全书固定用一条声线；
  - 分不到的列进缺口清单，交给外来声线专项；
  - 分完的表给用户过目。

### 音色锚点（17 号票的规则，新声线 15 号票补）

每条声线一段锚点，规则对所有声线一样，不按人调：

| 项 | 值 |
|---|---|
| 说话人向量 | 这条声线 60 句原声的 Qwen3 说话人向量取平均（`rawref.MEAN_N`），从候选里按固定种子随机取，长度缩放到单句向量的平均值 |
| 原声候选 | 三条路线（`bakeoff.REF_ROUTES`）里 1.5–12 秒、测得出音高和语速的有声台词，去掉小样和〈2002〉的句子。不到 60 句的从全书所有路线取，还不够就全部用上 |
| 文本 | 春希、雪菜、依绪、武也沿用旧定妆音的文本；新声线念挑锚点片段的游戏中文译文；都套读音表，再去掉拼音标注（`rawanchor.plain`，Qwen3 不认） |
| 挑锚点片段 | `rawref.pick_anchor`：3–8 秒的平稳句，按音高、语速离中位数的远近排序，凑满 10–18 秒。原声少、凑不满 10 秒的，先放宽平稳（3–8 秒带感叹的也算），再放宽时长（全部候选），已挑的留着接着凑（`rawref.RELAX`，生产 05 号票用户定的；全书只有本田、班主任用到） |
| 合成 | Qwen3-TTS Base 只用说话人向量（`x_vector_only_mode`），温度 0.6，一批 8 个候选，种子是 16 加批号，不变速 |
| 合格条件 | 四条都满足：没读错（字错率不比这批最低的高出 0.1 以上）；过质检（`bakeoff.ok`）；音高离目标不超过本人原声音高四分位距的一半；像原声过音色门槛 |
| 挑选 | 合格的取像原声最高的。都不合格就换种子再生成一批，最多 4 批；还不行就放宽质检和音高两条，在没读错、过门槛的里面取像原声最高的；再没有就在全部候选里取 |
| 目标音高 | 挑锚点片段的音高中位数 |
| 目标语速 | 4.2 字/秒 × 本人日语语速 ÷ 5.13，限制在 3.3–5.0。5.13 是春希、雪菜、依绪、武也四人日语语速的中位数，固定下来，不随加人变 |

- **截断**：IndexTTS 只取参考的前 15 秒。超长的锚点在 10–15 秒之间最安静的地方截断，尾部淡出 20 ms（`index_passage.anchor_clip`）。
- **生产用的锚点**（生产 05 号票）：全书 35 条声线都做好了（`rawanchor.make_lines`），放 `books/wa2/voices/锚点/<声线名>.wav`，登记在声线库每条的「锚点、锚点文本、锚点像原声、目标音高、目标语速」（`voicelines.anchor(声线名)` 取路径）；挑选明细在 `books/wa2/voices/锚点.yaml`，汇总表在 `锚点.md`。

  - 锚点生成后先给用户试听，每人配几句台词，认可了再进全书；

## 五、逐句合成

### 引擎

IndexTTS-2.5（`indextts.infer_v2_5`），在它自己的环境里跑（`indextts_batch.py`）：

| 参数 | 值 |
|---|---|
| 精度 | bf16，`use_cuda_kernel=False` |
| 语言 | `lang="ZH"` |
| 说话人参考 | 音色锚点的前 15 秒 |
| 情绪 | `perform.vec` 不全为 0 时，先过 `normalize_emo_vec(apply_bias=True)`，总和压到 0.8 以内；讲述模式用 `emo_audio`＝讲述定妆音；都不是就不给 |
| `emo_alpha` | 1.0，强弱已经写进向量 |
| 采样 | `use_random=False`，每个候选先 `torch.manual_seed(种子)` |
| 生成上限 | `max_mel_tokens = ⌈(3.5 + 0.5 × 字数) × 25⌉`，2.5 版每秒 25 个语义 token |
| 时长 | 不用 `duration_factor`。语速放在混音里（11 号票用户听时长 A/B 定的） |

### 文本规范化（`synth.tts_text`）

- 台词去掉外层引号；
- 全角字母数字转半角，夹在中间的全角空格一起转；
- 换行合并；
- **套读音表** `books/wa2/lexicon.yaml`（生产前验证）：
  - IndexTTS-2.5 支持 `<字|拼音声调>` 这种标注，读音表可以直接写成这种形式；
  - 先加一条「雪菜」→「`<雪|XUE3>`菜」，因为「雪」常被读成二声（10、11 号票）；
  - 标注里的字母和数字不算进字数。语速、时长上限和生成上限都按字数算。
- **去掉句首的「～」**（生产前验证）：小样 73 号「～～～呃！？」读出了一个「克」。句中的「～」照旧，没听出问题。
- 只有标点、没有字的句子不合成，插 0.8 秒静音。

### 按轮生成

- **种子**：每句的候选按固定种子排好，第 k 个的种子是 `idx × 100 + k`。
- **一轮一个候选**：
  - 第 1 轮给每句生成第 0 个候选，然后挑选；
  - 第 2 轮只给还没过关的句子生成第 1 个，依此类推，最多 4 轮（k = 0–3）；
  - 种子和顺序都不变，结果和"一次生成 4 个再按顺序挑"一样，只是不再生成用不到的候选。
- **一轮跑很多章**：IndexTTS 每轮要加载 20–30 秒模型，所以一轮把很多章放在一起跑，比如一个部。
- **补轮次**：4 轮下来没有一个候选过音色门槛的句子，换种子再补最多 4 轮（k = 4–7），有一个过了就停。

## 六、挑选和质检

### 每个候选

1. **读入**：转 48 kHz（`voices.to48k`，soxr HQ），切掉首尾静音（阈值是峰值的 2%，两头各留 0.1 秒）。
2. **变速**：按 `tempo` 用 atempo 变速，不变调。
3. **音色门槛**：
   - 去掉首尾静音后 ≥1.5 秒的，用 CAM++ 和这条声线 300 句原声的嵌入中心比，像原声要 ≥ 这条声线的音色门槛；
   - 不到 1.5 秒的不查音色，声纹在短句上测不准。
4. **质检**（`bakeoff.ok`）：
   - 时长 ≤ (2.5 + 0.5 × 字数) ÷ `tempo` 秒；
   - 句内变调：每半秒估一次音高，最高的一段 ≤ 目标音高的 1.45 倍；
   - 偏差分 < 0.45。偏差分 = 2 × |ln(音高 ÷ 目标音高)| + |ln(语速 ÷ (目标语速 × `tempo`))|，大约相当于音高偏 ±15% 或语速偏 ±45%；不到 4 个字的不算语速。

### 过关和挑选

- **过关就停**：按候选顺序看，第一个既过音色门槛又过质检的就停。
- **都没过关时**：在过了音色门槛的候选里，挑偏差分最小的（句内变调超过 1.3 倍的另加罚分，`bakeoff.finish`）。补完轮次仍然一个都没过音色门槛，就取像原声最高的。
- **拉回语速**：挑中的候选，语速拉回"目标语速 × `tempo`"的 0.85–1.2 倍之间（atempo）。
- **读音不参与挑选**：不会因为读错而重试。

### 复核清单

每章一份，列出两类句子：
- 补完轮次还没过音色门槛的句子，这些取的是像原声最高的候选；
- 读音可疑的句子：
  - 挑中的那一句用 Whisper 识别回文字，转成带声调的拼音，再和原文比，错率超过 0.3 就进清单；
  - 同音字不算错。所以「依绪」被识别成「依序」不会进清单，「雪」读成「学」会进。

### 新规则在现成候选上的效果

拿 11 号票定版现成的候选，按本节规则重挑了一遍。这是在干声上算的，没出 MP3，也还没试听：

| | 小样 | 〈2002〉 |
|---|---|---|
| 平均每句用几个候选 | 1.77 → 1.49 | 1.57 → 1.29 |
| 用满 4 个的句子 | 9 → 5 | 8 → 3 |
| 4 个都没过音色门槛 | 1 句：依绪 2 号「新年快乐，春希」，最高 0.565，门槛 0.589 | 0 |
| 挑中的候选变了 | 5 句 | 6 句 |

- **换了候选的多是短句**：短句不查音色以后，第一个过质检的就用。
  - 其中〈2002〉24 号「呼」从 0 号换成了 2 号。用户之前听过、觉得 1.28 秒正好的是 0 号（生产前验证）。
- **依绪 58 号**：换成 3 号候选，像原声 0.608，过了门槛。
- **剩下用满 4 个的句子**：都是质检没过，包括依绪两句喊叫（56、58 号，音高 333 Hz）、雪菜 84 号、春希 50、54、56 号。

## 七、混音和输出

### 后期链

逐句处理，在 48 kHz 单声道上做（`mix.process`）：

1. **削高频**：缓4k，一阶低通，从 4 kHz 往上每倍频程 −6 dB。旁白和台词一样（19 号票）。
2. **拉平响度**：每句拉到 −20 dBFS（RMS）。
3. **按类别和效果处理**：

| 情况 | 处理 | 立体声 |
|---|---|---|
| 心理活动 | 120 Hz 高通，−4 dB，内心混响（0.35 秒，湿声 0.18） | 居中 |
| 电话（先做，再按类别） | 300–3400 Hz 带通，轻度削波（tanh × 3），响度 × 0.8 | 跟类别 |
| 回忆 | 6 kHz 低通，−3 dB，混响（0.8 秒，湿声 0.3） | 台词按角色偏，其余居中 |
| 旁白等非台词 | 干声，−1.5 dB | 居中 |
| 台词、效果为无 | 房间混响（0.25 秒，湿声 0.12） | 按角色偏 |
| 台词、电话或书信短信 | 干声 | 按角色偏 |

4. **加减音量**：按 `perform.gain` 加减（11 号票）。
5. **立体声定位**：等功率定位，角色的偏移在 `cast.yaml` 的 `pan`，不超过 ±0.2。

### 拼接

- **句间静音**：同一个人连着说 0.25 秒，换人 0.4 秒，旁白前后 0.5 秒；有 `pause` 的取两者里大的。
- **防削顶**：整段峰值超过 0.97，就整体压下来。

### 输出

- **MP3**：每章一个，44.1 kHz、160 kbps 联合立体声。ID3v2.3 里写书名、章节名、曲目序号和封面，按部分文件夹（方案）。
- **只出带电话效果的一版**：无电话效果版只留在试做里。
- **附件**：
  - 对照剧本：时间戳、谁、类别、情绪、效果、台词，加上【前停 N 秒】标记和表演一列；
  - 复核清单。

## 八、速度、成本和全书预估

**全书规模**：游戏全部路线去重后 172 份剧本，有字要念的 65,488 句，发音字 125.2 万（含标点 154.1 万）。以前各票都按 168 万字折算全书耗时，偏高大约三成；11 号票按 11 万句估的 `claude -p` 成本也偏高。

| 项 | 实测 | 全书 |
|---|---|---|
| 合成（只算用到的候选） | 按新规则每字 0.290 秒；定版原来的规则是 0.314 秒 | 约 101 小时 |
| 补轮次 | 大约 1% 的句子多生成最多 4 个候选 | 不到 +3% |
| 挑选和质检 | 每个候选约 0.15 秒：读入加变速 0.07，CAM++ 0.05，质检 0.02 | 约 4.5 小时 |
| IndexTTS 加载模型 | 每轮 20–30 秒 | 按部分轮跑，1 小时以内 |
| 单个候选的实时率 | 0.74–0.82 | — |
| 表演设置那一遍 `claude -p` | 每句约 $0.007、1.1 秒。Opus 5.5，列表价；试做时要了七个字段 | 约 $460、20 小时（串行）；只要三个字段后（生产 02 号票实测），输出 token 和耗时都少约四成 |
| 剧本化、停顿两遍 `claude -p` | 没单独计 | 估计和表演设置那一遍同一个量级 |
| 成品时长 | 每字 0.318 秒：小样 186 秒 / 573 字，〈2002〉356 秒 / 1131 字，含句间静音和停顿 | 约 110 小时音频 |

- **GPU 部分**：合计约 106 小时，也就是 4.4 天。`claude -p` 不占 GPU，可以提前跑。
- **新规则的每字 0.290 秒**：是拿现成候选重挑算出来的，补轮次那 1% 的句子没算进去。
- **费用**：`claude -p` 用的是现有订阅，不另开 API（方案），列表价只作参考。

## 十、已知问题和后续

- **外来声线专项**：
  - 先用别的游戏的语音包：录音棚干声，一句一个文件，标好了是谁说的，处理方法和原声一样；
  - 影片要先分离人声、分出说话人、识别文字，工作量大，单独做；
  - 片源用户可以帮着找；
  - 声线库分不到的缺口交给它补。
- **读音**：
  - 「依绪」常被识别成「依序」「一叙」，这是同音，不是读错；
  - 「雪菜」的声调是真读错，10 号票里 14 处错了 5 处。
- **电子颤音**：IndexTTS-2.5 自带的电子颤音在 8 kHz 以下，只能靠缓4k 压轻，戴耳机听更明显（17、19 号票）。
- **RVC（09、12 号票，搁置）**：音色要是还不稳，或者想试试用 RVC 重过一遍声码器能不能去掉颤音，再拿出来。
- **按角色微调 TTS**：VoxCPM2 LoRA、GPT-SoVITS、Qwen3 SFT，等 RVC 有结论再说（地图的 Not yet specified）。
- **依绪和雪菜**：两人原声的相似度 0.53，要不要再拉开，等音色稳住后再听。
- **依绪喊叫**：音高冲到 333 Hz（小样 56、58 号），4 个候选都过不了质检，最后挑的是最接近的那个。
- **表演设置**：
  - 用户说有些句子 A 版（查表向量 × 强度）更好，没有逐句问是哪几句；
  - Claude 给的音量偏保守：轻声要 −3～−4 dB，实际只轻了 2.4 dB，整段限幅又吃掉 1–2 dB。
- **停顿**：每段只跑了一次，秒数稳不稳没测；"换一通电话多留 1–2 秒"那一档还没遇到过。
- **普通小说的说话人判断**：盲测 93%，另开地图。
