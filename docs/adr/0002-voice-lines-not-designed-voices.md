# 音色按声线管理，没编号的角色从声线库里分，不设计音色

音色锚点和音色门槛都按声线做。声线是一个声优的一种分得开的声音，不按角色算，也不按声优算：
- 同一个声优配得听不出是一个人的角色，算两条声线；
- 原声分不开的角色，合成一条声线。

没有自己语音编号的配角和龙套，从声线库里分一条现成的真人声线，不用 Qwen3 按文字描述设计音色。原因是门槛能统一：
- 真人声线有原声，所有人都能用同一条"像原声 ≥ P5"的音色门槛；
- 设计出来的音色没有原声可比，只能另设"像锚点 ≥0.65"的特例。

代价和约束：
- **可能不够分**：缺口交给外来声线专项，从别的游戏、影片克隆；
- **避免同场撞声**：同一个声优的声线，不分给可能同场的角色。
