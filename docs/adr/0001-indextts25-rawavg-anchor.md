# 正式合成用 IndexTTS-2.5 复刻原声平均锚点，不走 RVC 或按角色微调

音色稳定靠零样本复刻加逐句质检，不靠把音色训进模型：
- 每条声线用几十句原声的平均说话人向量（Qwen3），复刻一段中文音色锚点；
- IndexTTS-2.5 拿这段锚点当说话人参考，情绪另用情感向量给。

技术报告当初把"按角色训练 RVC 做音色转换"排在第一，没这么做的原因：
- 这套做法已经过了音色门槛（小样 30/32、〈2002〉51/51），认人准确率 100%，用户试听认可；
- 不用为每个角色训练模型。

RVC（09、12 号票）和按角色微调 TTS 都搁置了。以后音色还不稳，或者想试试去掉 IndexTTS-2.5 的电子颤音，再拿出来。

## Considered Options

- **混合版（Qwen3 复刻 VoxCPM2 做的定妆音）**：等于"复刻的复刻"，过音色门槛只有 20/30、33/43。
- **Qwen3 原声平均版**：音色稳，但 Qwen3 复刻模式不接受情绪，情绪进不来（07 号票）。
- **豆包预置音色**：听感不如本地，音色也不是本人（14 号票）。
- **IndexTTS-2.5 加 RVC 兜底**：搁置，原因见上。
