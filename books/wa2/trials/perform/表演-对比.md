# 11 号票：逐句表演设置（A/B/C）和基线对比

基线是 19 号票的成品（`books/wa2/trials/resample/*-重采样-缓4k.*`）：17 号票定版锚点、18 号票的停顿、soxr、缓4k，情绪按剧本 `mood` 查 `index_passage.EMOTION`。
三版和基线用同一套锚点、同一句、同一种子（`idx×100+k`），只差表演设置。

## 定论（用户试听定的）

- **情绪用 B**：Claude 看性格卡和整段剧本，逐句直接给 8 维情感向量。试听合集（基线 → A → B）："大多数B更好一些，有些A好"。
- **语速放混音**：时长 A/B 里选了第三遍"混音变速"。合成不拉长，候选读进来先按 `tempo` 用 atempo 变速，再照常挑选。
- **音量放混音**：每句拉平响度以后按 `gain` 加减（用户一开始就定的）。
- 定版是 `2.5-表演B混音`：`小样-IndexTTS-2.5-表演B混音.*`、`2010-11-25 〈2002〉-IndexTTS-2.5-表演B混音.*`（MP3、对照剧本、指标）。

| 片段 | 版本 | 过门槛 | 像原声 中位 | 配对差 中位 | 认人·原声中心 | 字错率 中位 | 字错率 >0.3 |
|---|---|---|---|---|---|---|---|
| 小样 | 基线 | 30/31 | 0.62 | — | 42/43 | 0.018 | 4 |
| 小样 | B（合成拉长） | 31/32 | 0.63 | +0.001 | 43/43 | 0.046 | 5 |
| 小样 | **B 混音变速（定版）** | 30/32 | 0.62 | +0.005 | 43/43 | 0.054 | 3 |
| 〈2002〉 | 基线 | 47/47 | 0.65 | — | 58/58 | 0.033 | 5 |
| 〈2002〉 | B（合成拉长） | 51/51 | 0.65 | −0.006 | 58/58 | 0.026 | 4 |
| 〈2002〉 | **B 混音变速（定版）** | 51/51 | 0.63 | −0.019 | 58/58 | 0.026 | 3 |

- **混音变速在被拉长的句子上像原声低一点**：〈2002〉春希旁白里语速不是 1 的 28 句，比基线 −0.021（合成拉长是 −0.010）；雪菜 13 句 −0.017（−0.004）。语速是 1 的句子和基线一样。全部仍过门槛。
- **候选配对**（不经挑选，不变速，只差情绪向量）：像原声差 −0.02～+0.02，过门槛、认人不变；武也那一句（「新年快乐～」，B 加了喜 0.35）音高 159 → 187 Hz，仍过门槛。
- **「呼」和轻声**：
  - 「呼」0.28 → 1.28 秒；
  - 轻声比同一段的其他台词轻 2.4 dB（小样）、3.9 dB（〈2002〉），基线是 0；
  - 慢 10–30%；
  - 春希轻声 131–155 Hz（基线 130–158），没被抬高。
- **速度**：每字 0.40 秒（小样，基线 0.43）、0.27 秒（〈2002〉，基线 0.26），不变；atempo 的耗时可以不计。

## 做法

**表演设置**（`readbook/perform.py`）：每段剧本调一次 `claude -p`（只发文字），送去的是：
- 出场人物的性格卡（`books/wa2/cast.yaml` 新加的 `card`：性格 / 情绪外露 / 声音，9 个主要角色同一格式）；
- 整段剧本和已有字段（类别、说话人、效果、`mood`、`instruct`、`pause`），叙述者平常的旁白和心里话标成讲述模式；
- 现在的查表值，以及引擎的限制（权重越大越容易漏音色，宁淡勿浓）。

逐句返回 7 个字段，写进 `表演-<剧本>.jsonl`，已有剧本字段一个不动。三版共用后三项，只差"情绪从哪来"：

| 字段 | 范围 | 用在哪 |
|---|---|---|
| `strength` | 0–1 | A：查表向量乘这个数（`emo_alpha`） |
| `vec` | 8 个 0–1 | B：直接当情感向量，和查表的一样过 `normalize_emo_vec`（偏置、总和压到 0.8） |
| `emo` | ≤20 字 | C：交给 IndexTTS 自带的情感模型（QwenEmotion）转成向量，再过 `normalize_emo_vec` |
| `tempo` | 0.5–1.25 | 三版：合成时 `duration_factor = 1/tempo`；挑选时目标语速也乘 `tempo`，免得被拉回去 |
| `gain` | −9 到 +3 dB | 三版：混音时每句先拉到同一响度，再加减 |
| `why` | ≤25 字 | 只给人看（对照剧本的「表演」列） |

- 讲述模式的句子不换情绪（仍拿讲述定妆音当情感参考），只用 `tempo` 和 `gain`。
- `duration_factor` 乘在 s2mel 的目标长度上，在语义 token 生成之后：同一种子、同一向量的候选，内容和基线一样，只是整体拉长。
- 和基线完全一样的任务（语速 1、向量相同）直接拷基线的候选，不重新合成。

**时长放哪**（用户定的："合成为主，短句加 A/B"）：「呼」这类一两个字的叹词和轻声句，拿 A 版挑中的那个种子，再做一份不拉长、合成后用 atempo 变速的，排在一起听（`*-时长AB.mp3`）。

## 结果一览

过门槛只算去掉首尾静音后 ≥1.5 秒的句子。配对差是同一句在成品里的像原声和基线比。emotion2vec 只当旁证：数的是有明确情绪的句子（开心、兴奋、生气、难过、哭腔、惊讶）里，被识别成对应情绪的句数。

### 小样

| 版本 | 时长 | 过门槛 | 像原声 中位 | 配对差 中位 | 掉到门槛下 | 认人·原声中心 | 字错率 中位 | 字错率 >0.3 | emotion2vec 对上 |
|---|---|---|---|---|---|---|---|---|---|
| 基线 | 3.0 分 | 30/31 | 0.62 | — | — | 42/43 | 0.018 | 4 | 7/12 |
| A | 3.1 分 | 30/32 | 0.62 | −0.002 | 2、70 | 43/43 | 0.018 | 3 | 7/12 |
| B | 3.1 分 | 31/32 | 0.63 | +0.001 | 2 | 43/43 | 0.046 | 5 | 6/12 |
| C | 3.1 分 | 31/33 | 0.63 | +0.010 | 3、68 | 43/43 | 0.064 | 4 | 7/12 |

### 〈2002〉

| 版本 | 时长 | 过门槛 | 像原声 中位 | 配对差 中位 | 掉到门槛下 | 认人·原声中心 | 字错率 中位 | 字错率 >0.3 | emotion2vec 对上 |
|---|---|---|---|---|---|---|---|---|---|
| 基线 | 5.7 分 | 47/47 | 0.65 | — | — | 58/58 | 0.033 | 5 | 8/13 |
| A | 5.9 分 | 49/50 | 0.65 | −0.009 | — | 57/58 | 0.000 | 3 | 5/13 |
| B | 5.9 分 | 51/51 | 0.65 | −0.006 | — | 58/58 | 0.026 | 4 | 4/13 |
| C | 5.9 分 | 48/49 | 0.61 | −0.009 | — | 58/58 | 0.026 | 4 | 5/13 |

- 过门槛的分母变了，是因为放慢以后多了几句够 1.5 秒；掉到门槛下的几句（小样依绪 2 号、70 号、武也 3 号、雪菜 68 号）原来就贴着门槛（依绪门槛 0.59）。
- 字错率 >0.3 的几乎都是人名（「依绪」→「依序」「一叙」，「雪菜」→「学菜」「血菜」），三版和基线都有，看不出哪版系统性地读错。
- emotion2vec 对上的句数三版都没比基线多，〈2002〉还少了几句。旁证而已，以试听为准。

## 音色：同一句同一种子的候选配对（不经挑选）

每句 4 个候选全部计入（`index_passage pair`）。

| 片段 | 组 | 像原声 配对差 A / B / C | 音高 Hz 基线 → A / B / C |
|---|---|---|---|
| 小样 | 春希台词 | −0.02 / +0.01 / **−0.07** | 150 → 150 / 150 / **175** |
| 小样 | 春希讲述 | 0 / 0 / 0 | 136 → 135 / 135 / 135 |
| 小样 | 雪菜 | −0.03 / −0.01 / −0.02 | 320 → 320 / 320 / 320 |
| 小样 | 依绪 | 0 / +0.02 / +0.01 | 232 → 227 / 232 / **282** |
| 小样 | 武也（1 句） | 0 / −0.02 / **−0.05**（过门槛 3/4 → 1/4） | 159 → 162 / 183 / **225** |
| 〈2002〉 | 雪菜 | −0.01 / +0.02 / 0 | 314 → 314 / 320 / 314 |
| 〈2002〉 | 春希台词（短句） | — | 145 → 136 / 142 / **176** |
| 〈2002〉 | 春希讲述 | −0.01 / −0.01 / −0.02 | 139 → 140 / 140 / 140 |

- **A、B 不带偏音色**：配对差都在 ±0.03 以内，过门槛、认人不变。B 给不少「平常」台词加了淡淡的向量（如武也「刻意装出轻快」喜 0.35），也没带偏。
- **C 把音高抬上去了**，和 10 号票轻声向量抬春希音高是同一回事。原因在情感模型：
  - 它几乎只认一种主情绪，而且总和顶到 0.8 上限：「紧张，压低声音」→ 惧 0.73，「温柔又忧伤，很轻」→ 哀 0.77，「轻轻的一点意外，很淡」→ 惊讶 0.68；
  - 「淡淡的」「很轻」这类浓淡词不认，没有情绪词的就落到"平静 0.56"；
  - 混合情绪会丢一半：「寂寞，强撑着笑」→ 只剩哀 0.73，笑意没了；还有认错的，「带着哭音，轻轻责怪」→ 怒 0.54；
  - 过完偏置和上限，C 的向量总和中位 0.80（最低 0.56），B 中位 0.61（0.31–0.80），查表的轻声 0.56。

- **「呼」拉长了**：Claude 给的语速 ×0.55（`duration_factor` 1.82），成品 0.28 → 0.68–1.20 秒。同一个拉长倍数，B 的那个候选本身就长，所以到了 1.2 秒。

- **音高**：

  - C 的春希轻声普遍抬到 ~200 Hz，小样开头「啊…」被拖成 2.3 秒、267 Hz。

## 成本

- **剧本化多出来的 `claude -p`**：每段一次，模型是 claude -p 默认的 Opus 5.5。

  | 剧本 | 句数 | 送去 | 返回 | 耗时 | 费用（按列表价） |
  |---|---|---|---|---|---|
  | 〈2002〉 | 65 | 1.09 万字 | 0.82 万字 | 71 秒 | $0.60 |
  | 2011-01-01（小样所在的整份） | 157 | 2.30 万字 | 2.01 万字 | 179 秒 | $0.95 |

  - 合计每句约 $0.007、1.1 秒、返回约 136 个 token。
  - 全书按这两份剧本的平均（每句 15 字）约 11 万句，约 $780、35 小时（串行）。
  - 正式流程只要一种做法的字段（比如只要 vec、tempo、gain），返回能少一半左右。
- **合成速度**：用到的候选的生成时间，每字秒数和全书折算如下。

  | 片段 | 基线 | A | B | C |
  |---|---|---|---|---|
  | 小样 | 0.43 秒（8.5 天） | 0.43（8.4） | 0.38（7.4） | 0.46（8.9） |
  | 〈2002〉 | 0.26 秒（5.1 天） | 0.29（5.6） | 0.27（5.2） | 0.35（6.7） |

  - A、B 基本不变；`duration_factor` 只多算一点 s2mel；
  - C 慢一些：没过质检、要多试的句子多了（平均每句 1.88–1.95 个候选，基线 1.38–1.74），情感模型（Qwen 0.6B，1.2 GB）要另外加载；
  - 机器状态的差别有一成上下。

## 命令

```

uv run python -m readbook.perform 时长 小样|"2010-11-25 〈2002〉"     # 时长 A/B
uv run python -m readbook.evaluate 小样|2002 <MP3> --锚点 春希=books/wa2/trials/anchor-rule/锚点/春希.wav …（四人）
uv run python -m readbook.index_passage pair 小样 2.5-原声平均锚点新规 2.5-表演B
```
