# 原声平均锚点交给 IndexTTS-2.5（16 号票）

2026-10-28，RTX 5090 笔记本。和 10 号票的 2.5 版（`books/wa2/trials/indextts/`）、混合版基线（`books/wa2/baseline/*-混合版-5090.*`）比。

## 怎么做的

- **第一步：重做锚点**。用原声平均版（Qwen3 只用本人 60 句原声的平均说话人向量）按旧定妆音的文本重做四人的音色锚点，见 `锚点对比.md`。
  - 只有春希明显更像原声：0.57 → 0.79。
  - 雪菜、依绪持平，武也更差。
  - 用户定的规则：每人用像原声更高的那个锚点。实际只换了春希。
- **第二步：IndexTTS-2.5 只换说话人参考**。春希用新锚点，其余三人照旧。下面这些全照 10 号票：
  - 情感参考：春希讲述模式用他的讲述定妆音；
  - 情感向量、质检目标、每句 4 个候选和种子、挑选规则。挑选时的"像锚点"和所用的锚点比。
- **两版只差在春希的句子上**：固定种子下，IndexTTS-2.5 的输出可以复现。雪菜、依绪、武也的候选和 10 号票逐样本一样（小样 108/108、〈2002〉72/72）。所以：
  - 春希的候选可以和 10 号票同一句、同一种子逐个配对，见 `*-配对-2.5-2.5-原声平均锚点.md`；
  - 其他人的句子是同一份工作，可以拿来校准两次运行之间机器快慢的差别。
- 命令：
  ```
  uv run python -m readbook.rawanchor                                        # 重做锚点、量、定采用
  uv run python -m readbook.index_passage 2.5-原声平均锚点 小样|"2010-11-25 〈2002〉"
  uv run python -m readbook.index_passage pair 小样 2.5 2.5-原声平均锚点
  uv run python -m readbook.evaluate 小样 <MP3> --锚点 春希=books/wa2/trials/rawavg-anchor/锚点/春希.wav
  ```

## 结论

- **采用全员版：四人都用原声平均锚点当 IndexTTS-2.5 的说话人参考**。用户试听全员版"比刚才好"。规则对所有角色一样，不再按声纹挑新旧。
- 声纹量出来的锚点本身，只有春希明显更像原声（0.57 → 0.79）。但试听以全员版为好，所以锚点像不像原声不能单独拿来决定用哪个，要以试听为准。
- 成品：
  - **春希**明显更像本人：台词 0.51 → 0.72，讲述 0.55–0.58 → 0.68；
  - **雪菜**略更像、和别人分得更开、语速快了，代价是音高偏高约 5%、读错的句子多两三句；
  - **依绪**语速接近目标；
  - **武也**唯一的一句没过门槛，要在他戏多的段落上再听；
  - 过门槛 94–100%，认人 100%。
- 新锚点偏高的音高没有带进春希的成品。10 号票里春希「轻声」被向量抬高的问题，在没另调向量的情况下也消失了。
- 语速：春希台词慢约一成，正好回到目标；雪菜、依绪变快。原声平均版"偏慢"并没有整体带进来，锚点的语速会带进成品。
- 速度：两段合计，只算用到的候选的生成时间，每字 10 号票 2.5 版 0.366 秒、只换春希 0.383 秒、全员 0.321 秒。
  - 全员版比 10 号票少一成多，今天机器还慢 3–10%；
