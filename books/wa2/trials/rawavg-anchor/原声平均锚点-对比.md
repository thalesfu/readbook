# 原声平均锚点交给 IndexTTS-2.5（16 号票）

2026-10-28，RTX 5090 笔记本。和 10 号票的 2.5 版（`books/wa2/trials/indextts/`）、混合版基线（`books/wa2/baseline/*-混合版-5090.*`）比。

## 怎么做的

- **第一步：重做锚点**。用原声平均版（Qwen3 只用本人 60 句原声的平均说话人向量）按旧定妆音的文本重做四人的音色锚点，见 `锚点对比.md`。
  - 只有春希明显更像原声：0.57 → 0.79。
  - 雪菜、依绪持平，武也更差。
  - 用户定的规则：每人用像原声更高的那个锚点。实际只换了春希。
- **第二步：IndexTTS-2.5 只换说话人参考**。春希用新锚点，其余三人照旧。下面这些全照 10 号票：
  - 情感参考：春希讲述模式用他的讲述定妆音；
  - 情感向量、质检目标、每句 4 个候选和种子、挑选规则。挑选时的"像锚点"和所用的锚点比。
- **两版只差在春希的句子上**：固定种子下，IndexTTS-2.5 的输出可以复现。雪菜、依绪、武也的候选和 10 号票逐样本一样（小样 108/108、〈2002〉72/72）。所以：
  - 春希的候选可以和 10 号票同一句、同一种子逐个配对，见 `*-配对-2.5-2.5-原声平均锚点.md`；
  - 其他人的句子是同一份工作，可以拿来校准两次运行之间机器快慢的差别。
- 命令：
  ```
  uv run python -m readbook.rawanchor                                        # 重做锚点、量、定采用
  uv run python -m readbook.index_passage 2.5-原声平均锚点 小样|"2010-11-25 〈2002〉"
  uv run python -m readbook.index_passage pair 小样 2.5 2.5-原声平均锚点
  uv run python -m readbook.evaluate 小样 <MP3> --锚点 春希=books/wa2/trials/rawavg-anchor/锚点/春希.wav
  ```

## 春希的音高和语速有没有被带进来

新锚点本身 174 Hz，比他的原声（160 Hz）和旧定妆音（158 Hz）高约一成，语速 3.54 字/秒（旧的 4.01）。成品里春希的句子：

|---|---|---|---|
| 小样 | 台词·平常（4） | 150 / 161 / 160 | 4.79 / 4.45 / **3.91** |
| 小样 | 台词·轻声（6） | 184 / 193 / **134** | — |
| 小样 | 讲述（6） | 156 / 142 / 138 | 5.28 / 4.58 / 4.38 |

| 〈2002〉 | 轻声（台词 2、讲述 1） | 218、190 / 161、195 / **137、144** | — |
| 〈2002〉 | 台词·生气（1） | 205 / 262 / 243 | — |

质检目标：平常 158 Hz、4.01 字/秒，讲述 158 Hz、4.44 字/秒，他的轻声定妆音 152 Hz。

- **音高没被带进来**：平常台词 160 Hz，讲述 138–139 Hz，都和 10 号票一样，贴着目标。
- **10 号票的「轻声」问题没了**：
  - 10 号票里，轻声向量把春希抬到 161–195 Hz。用户听出不像他，原因就在这里。
  - 换新锚点后是 134–144 Hz，和 2.5-ref（拿轻声定妆音当情感参考）的 109–135 Hz 相近，但用的还是 10 号票那个轻声向量，没另调。
  - 看来是旧锚点让向量更容易把他推高。
- **语速带进来一部分，没低于目标**：
  - 台词慢了约一成：变速前 4.49 → 3.94，成品 4.45 → 3.91，正好落在他的目标 4.01 附近；
  - 讲述只慢 2–4%；
  - 要拉快的句子数没变：小样 11 → 12，〈2002〉7 → 6；
  - 和混合版比还是慢（台词 4.79、讲述 4.96）。听着拖不拖，看试听。

## 春希和武也还分不分得开

- **锚点本身更近了**：新春希锚点和武也锚点的相似度 0.38 → 0.62。
- **成品还分得开**：
  - 认人 100%（两个尺子都是）；
  - 候选级：春希的候选最像的别人都是武也。像武也的中位上升了（小样 0.39 → 0.47，〈2002〉0.44 → 0.47），但像自己升得更多（0.56 → 0.69，0.59 → 0.69）；
  - "像自己 − 像最像的别人"反而拉大：小样台词 +0.18 → +0.24，讲述 +0.16 → +0.22，〈2002〉讲述 +0.15 → +0.21；
  - 像武也最高的一个候选是 0.54 / 0.56，仍远低于像自己。
- 小样里武也只有一句，〈2002〉里没有他。两人同场的段落，到全书生产前还要再听。

## 情绪

只换了说话人参考，情感向量和讲述参考都没动。

emotion2vec 在这几段上很不靠谱（10 号票 2.5 版把春希 31 句平常讲述里的 26 句认成"生气"），只能当旁证：
- 〈2002〉春希平常讲述：认成"生气"的 26 → 13 句，"中立"5 → 17 句（混合版 26 句中立）；
- 难过的心里话（4 句）：认成"难过"的 0 → 3 句；
- 小样平常讲述："生气"5 → 3 句。

像是新锚点让春希不那么紧绷，情绪也没丢。到不到位以试听为准。

- **其他人的句子是同一份工作**，今天跑小样时慢了约一成（0.86 → 0.94）。这是机器状态的差别，运行环境文档里记过；模型加载也从 19 秒变成 31 秒。扣掉这一成，春希的单个候选实时率没变。
- 小样里春希的台词慢了，同样的字多出 8% 的音频，生成时间也跟着多一点。〈2002〉以讲述为主，没变。
- **结论：速度基本不变**。全书仍按 10 号票的估算，约 8.5 天；小样那种台词多的段落可能多一两个百分点。
- 今天的墙钟时间：小样 743 秒、〈2002〉1005 秒，含模型加载、挑选、CAM++ 和混音。

## 其他

- 读音：春希的字错率中位，小样 0.038 → 0.000，〈2002〉0.034 → 0.029；>0.3 的句数不变。
- 「雪菜」读错声调的问题不受影响：雪菜的句子和 10 号票是同一份音频。

## 结论（待试听确认）

- 原声平均版重做的锚点，只有春希比旧定妆音更像原声。按"每人用更像原声的锚点"只换春希后：
  - 春希在 IndexTTS-2.5 成品里明显更像本人（台词 0.51 → 0.72，讲述 0.55–0.58 → 0.68）；
  - 过门槛、认人都保持 97–100%，其他人不变。
- 新锚点偏高的音高没有带进成品。10 号票里春希「轻声」被向量抬高的问题，在没另调向量的情况下也消失了。
- 语速：台词慢约一成，正好回到目标；讲述基本不变。
- 和武也的锚点更近了，但成品里分得更开。
- 速度不变。
